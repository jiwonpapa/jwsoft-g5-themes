# JW SOFT 테마 상품 지원 정책

- 적용 대상: JW SOFT 유료 그누보드5·영카트5 테마 상품
- 적용 기간: 구매일로부터 12개월
- 기본 원칙: **지원 환경에서 재현되는 상품 자체 결함만 접수한다.**

## 1. 지원 대상

| 구분 | 지원 기준 |
| --- | --- |
| 테마 자체 오류 | 상품 설명에 명시된 기능이 지원 환경에서 정상 작동하지 않고 동일 증상을 재현할 수 있는 경우 |
| 테마 코드 보안 취약점 | 제공한 테마 코드에서 발생하는 XSS, SQL 주입, 권한 우회, CSRF 등 재현 가능한 취약점 |
| 배포 파일 문제 | 필수 파일 누락, 파일 손상, 잘못된 경로 또는 설치 문서 오류로 정상 설치가 불가능한 경우 |
| 공식 업데이트 회귀 | JW SOFT가 배포한 업데이트 후 기존 명시 기능이 작동하지 않는 경우 |
| 지원 버전 호환 오류 | 상품에 명시한 그누보드5·영카트5, PHP, 브라우저 범위 안에서 발생하는 오류 |

설치 오류는 배포 파일이나 설치 문서의 결함이 원인일 때만 지원한다. 서버 설정, 권한, 경로 변경, 호스팅 제한과 기존 사이트 충돌은 지원 대상이 아니다.

테마와 별도 플러그인은 서로 다른 상품으로 판정한다. 테마팩에 포함되지 않은 `jw-editor for G5`, 예약·업로더·외부 연동 플러그인의 설치·설정·오류는 테마 CS에 포함하지 않는다. 별도 플러그인을 구매한 경우에도 그 플러그인의 지원 환경·기간·문의 절차를 적용한다.

## 2. 지원하지 않는 문의

- 로고·색상·폰트·메뉴·문구·이미지의 변경 위치와 변경 방법
- HTML·CSS·PHP 수정, 화면 배치 변경, 반응형 조정과 고객사별 디자인 변경
- 콘텐츠 입력, 게시판·메뉴 생성, 초기 설정, 설치·이전·업데이트 대행
- 서버·도메인·DNS·SSL·메일·데이터베이스·백업·복구·성능 문제
- 해킹 사고 대응, 악성코드 제거, 유출 계정 복구와 서버 보안 설정
- 그누보드5·영카트5 코어 자체 오류, 외부 플러그인·스킨·수정 코드와의 충돌
- 상품에 명시하지 않은 PHP·G5·브라우저·호스팅 환경의 문제
- 지도·예약·결제·문자·소셜 로그인 등 외부 서비스의 계약, 설정과 장애
- SEO, 의료광고 심의, 병원별 문구 검토와 법률 자문
- 검색엔진 수집 시점·노출·순위·리치 결과 보장, 서치콘솔 등록과 외부 SEO 플러그인 충돌 분석
- 사용 교육, 제작 방법 상담, 견적 상담과 고객 프로젝트 납기 대응

로고·색상·폰트·메뉴 등 자주 바꾸는 항목은 상품·버전별 온라인 매뉴얼에서 구매자가 직접 확인한다. 문서는 제공하지만 구매자별 변경 방법 안내와 대행은 제품 CS에 포함하지 않는다.

테마가 지원 화면에서 출력한 JSON-LD·Microdata·일반 페이지 meta의 문법 오류, 실제 화면과 다른 값, 비공개 데이터 노출과 설정 저장 오류는 테마 자체 결함으로 지원한다. 검색엔진의 판단, 문구 작성과 외부 SEO 기능 운영은 지원하지 않는다.

## 3. 온라인 매뉴얼 우선 처리

- 설치·업데이트·롤백·변경 위치·자가진단은 온라인 매뉴얼을 공식 답변으로 사용한다.
- 매뉴얼 URL에는 상품 slug와 적용 버전을 표시한다.
- 같은 문의를 개별 설명으로 반복하지 않고 해당 절차의 정확한 URL로 안내한다.
- 매뉴얼 설명이 틀렸거나 빠져 정상 작업이 불가능하면 문서 결함으로 접수하고 수정한다.
- 매뉴얼 절차대로 원본 테마에서 재현되는 오류는 테마 자체 오류 판정 절차로 넘긴다.
- 고객 수정 코드, 서버 설정, 외부 플러그인을 분석해 주는 원격 지원은 제공하지 않는다.

## 4. 보안 문의의 경계

`보안 지원`이라는 넓은 표현은 사용하지 않는다. 상품 설명에는 **테마 코드에서 재현되는 보안 취약점 수정**이라고 적는다.

지원하는 보안 문의는 JW SOFT가 제공한 코드에 원인이 있고 재현 절차가 있는 경우다. 오래된 코어·외부 플러그인·서버 설정·탈취된 계정·고객이 수정한 코드가 원인인 침해 사고와 복구는 지원하지 않는다.

보안 취약점은 공개 게시글보다 비공개 문의로 접수한다. 확인된 취약점은 영향 범위와 수정 버전을 변경 이력에 기록한다.

구매자는 아래 정보를 한 번에 제출해야 한다.

1. 주문번호와 상품명·상품 버전
2. 그누보드5·영카트5 버전과 PHP 버전
3. 브라우저·기기·화면 크기
4. 문제가 발생한 화면과 재현 순서

6. 오류 메시지·로그·스크린샷
7. 원본 상품에서도 발생하는지, 고객 수정 코드와 외부 플러그인을 제거해 확인했는지

비밀번호, API 키, 주민등록번호, 환자 정보 등 비밀정보와 개인정보는 제거한 뒤 제출한다. 재현 정보가 없으면 원인 판정과 수정 일정을 확정하지 않는다.

## 6. 처리 원칙

- 접수 내용이 지원 대상인지 먼저 판정한다.
- 재현되는 상품 결함이면 수정 파일 또는 공식 업데이트로 처리한다.
- 동일 결함을 모든 구매자에게 적용해야 하면 개별 패치 대신 정식 버전으로 배포한다.
- 긴급한 테마 코드 보안 취약점과 설치를 막는 결함을 우선 처리한다.
- 고객 환경에서만 발생하는 문제는 지원 대상 판정에 필요한 최소 확인까지만 진행한다.
- 커스터마이징 작업을 별도 판매하더라도 테마 구매에 포함된 CS로 처리하지 않는다.

12개월이 끝나도 기존 설치분과 이미 받은 파일은 해당 상품 라이선스 범위에서 계속 사용할 수 있다. 이후 신규 업데이트와 문의 지원은 제공하지 않으며, 연장 상품이 있을 경우 별도로 구매한다.

연장 상품의 판매 가능 여부와 실제 다운로드 제한 방식은 아직 확정하지 않았다. SIR의 주기적 결제형 콘텐츠 금지, 기본 보증 조건, 기존 구매자의 권한을 확인한 뒤 운영 문구를 확정한다. [라이선스·업데이트 정책 조사](research/business/AVADA-LICENSE-AND-JW-UPDATE-POLICY-2026-09-21.md)를 기준으로 하며, 이번 조사로 기존 구매자 권한이나 지원 기간을 소급 변경하지 않는다.

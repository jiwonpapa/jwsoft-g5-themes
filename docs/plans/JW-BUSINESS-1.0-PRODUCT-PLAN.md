- 상태: 출시 구현 범위 확정, 최종 시각 방향 승인 전
- 기준일: 2026-09-20
- 페이지 구성 정정: 2026-09-21 — 기업개요·인사말·연혁 등 하위 페이지 각각 4~5종 요구 반영
- 구현 상태: 2026-09-21 제작 착수 지시 반영. 공식 basic 460개 반입·개명 완료, 화면 개편 전

첫 상품은 기존 판매중단 상품 페이지의 판매 이력을 유지하면서, 상품명과 소스를 새로 만든 **JW-Business 1.0**으로 교체합니다.

기존 판매 상품의 소스 위에 덮어쓰는 업데이트로 만들지 않습니다. `JW-Business 1.0`은 별도 테마 폴더에 설치하며 회원·게시글·첨부파일은 유지할 수 있지만 스킨, 이미지와 내용 페이지는 새 구조에 맞게 다시 연결합니다.

기존 판매중단 상품 페이지를 교체하므로 판매처가 기존 구매자에게 다운로드 권한을 유지하면 `JW-Business 1.0` 파일에도 접근할 수 있습니다. 이는 별도 신규 상품번호를 만들지 않는 운영 결정에 포함합니다. 기존 구매자에게 적용할 라이선스·업데이트·지원 기간의 기준일은 판매처 규정과 기존 판매 조건을 확인해 판매 문구와 `LICENSE-KO.txt`에 명시합니다.

2026-09-21 [라이선스·업데이트 정책 조사](../research/business/AVADA-LICENSE-AND-JW-UPDATE-POLICY-2026-09-21.md)에서 SIR의 주기적 결제형 콘텐츠 금지를 확인했습니다. 12개월 기본안과 가격은 유지하며, 선택적 업데이트 연장권의 허용 여부·가격·실제 다운로드 권한 운영은 미확정입니다. 받은 버전으로 만료 후 신규 고객 사이트를 제작하는 권리와 코드·자산별 재판매 제한 문구는 해당 조사안에 따라 구체화합니다.

G7 경험은 그대로 재적용하지 않습니다. 공식 basic 반입·독립 ZIP·전체 공개 화면·증거 구분·두 번째 사용 뒤 공통화는 채택하고, React·JSON UI·Page Builder·G7 편집 위젯과 하네스 구현은 제외합니다. 세부 판단은 [G7 유료 테마 경험의 G5 적용 검토](../research/common/G7-THEME-LESSONS-TRANSFER-REVIEW.md)를 따릅니다.

## 2. 조사 근거와 가격 논리

2026-09-20 공개 정보 기준 상위 기업 테마는 77,000~99,000원, 1도메인 라이선스 중심이며 누적 판매 170~430건을 기록했습니다. 최근 상품은 빠르게 늘었지만 판매 0건 비율도 높아져 메인 시안만으로는 방어력이 약합니다.

390,000원 무제한 라이선스는 기존 단품 가격과 비교하면 약 4~5개 사이트부터 구매자 비용이 낮아집니다. 목표 고객을 한 번만 사용하는 일반 사업자가 아니라 반복 납품 제작자로 한정하는 이유입니다. SIR 수수료를 20%로 가정하면 정상가 1건 정산액은 312,000원, 출시 실판매가 290,000원 1건은 232,000원입니다. 이는 수요 예측이 아니라 공개 가격과 라이선스 차이를 설명하는 산술 기준입니다.

출시 1개월 할인은 쿠폰으로 발급하지 않습니다. 판매 페이지의 실제 판매가격을 290,000원으로 변경하고 종료일에 390,000원으로 되돌립니다. 정확한 시작일·종료일은 상품 등록 시 기록합니다.

상품의 가격 근거는 테마 변형 개수가 아니라 다음 네 가지입니다.

1. 메인부터 회원·게시판·문의까지 연결된 전체 G5 사이트
2. 여러 고객 사이트에 반복 적용할 수 있는 사용권
3. 실제 납품에 쓰는 기업 페이지·게시판·데모 콘텐츠
4. 설치·변경·업데이트·원복을 설명하는 버전별 매뉴얼

## 3. 상품 한 문장

> 기업 홈페이지를 반복 제작하는 작업자가 최신 G5에 설치해 회사 소개, 사업, 실적, 미디어, 채용과 문의까지 바로 완성할 수 있는 무제한 사용 비즈니스 테마입니다.

## 4. 대상과 사용 장면

### 1순위

- G5로 중소기업 사이트를 반복 납품하는 웹 제작사
- 제조·산업·IT·건설·전문 서비스 기업을 담당하는 프리랜서
- 구형 기업 테마를 교체하려는 기존 G5 운영자

### 구매 후 완료해야 하는 일

- 테마 설치와 활성화
- 로고, 브랜드 색상과 대표 이미지 교체
- 제공된 직접 메뉴 설정에서 사용할 페이지 패턴 선택
- 일반 페이지 문구·이미지 교체와 게시판 생성·스킨 연결
- 회사 정보·연락처·지도·문의 경로 입력

관리자 페이지 빌더나 사이트 자동 생성기는 제공하지 않습니다. 구매자가 수정할 위치를 한 장의 변경 위치표와 온라인 매뉴얼로 제공합니다.

## 5. 전체 메뉴와 화면 범위

| 1차 메뉴 | 제공하는 2차 구조 | 구현 방식 |
| --- | --- | --- |
| 회사소개 | 기업 개요, 인사말, 비전·가치, 연혁, 조직도, 인증·수상, 오시는 길 | `/pages/*.php` + page recipe |
| 사업영역 | 사업 목록, 사업 상세 A, 사업 상세 B, 프로세스 | `/pages/*.php` + page recipe |
| 포트폴리오 | 전체, 분야별 분류, 상세 | 갤러리형 게시판 |
| 미디어 | 공지사항, 뉴스·보도, 자료실, 영상 | basic·webzine·download·video 게시판 |
| 인재채용 | 인재상, 복리후생, 채용공고 | `/pages/*.php` + 게시판 |
| 고객지원 | FAQ, 온라인 문의, 통합검색, 연락처 | G5 FAQ·문의 게시판·검색 |

영카트를 제외한 **G5 커뮤니티 고유 기능 전체**를 같은 디자인 체계에 포함합니다. 메인과 대표 게시판만 처리하고 나머지를 기본 스킨으로 남기지 않습니다.

- 테마 골격: `index`, `group`, `head`, `tail`, `head.sub`, `tail.sub`, PC·mobile 구조
- 게시판: basic·gallery의 목록·보기·쓰기·댓글과 검색·분류·페이징·첨부·비밀글·권한·빈 상태
- 회원: 로그인, 가입·약관·가입완료, 정보수정, 회원확인, 비밀번호 찾기·재설정, 프로필, 폼메일
- 개인 기능: 쪽지 목록·보기·쓰기, 포인트, 스크랩과 팝업 화면
- 콘텐츠: 정책·약관용 내용관리, FAQ, 1:1 문의 목록·보기·쓰기·답변
- 탐색·현황: 통합검색, 새글, 현재접속자, 인기검색어, 방문자, 설문
- 공통 블록: 최신글, 외부로그인과 PC·mobile 변형
- 정책 화면: 개인정보처리방침, 이용약관, 이메일무단수집거부와 푸터 사업자 정보
- G5 공통 흐름: CAPTCHA, 에디터 본문, 경고·권한·비밀글 확인과 테마 밖 공용 UI의 시각 연결

구현을 시작할 때 해당 G5 버전의 `theme/basic` 파일 목록을 기준 inventory로 고정합니다. 모든 파일은 `개편`, `그대로 상속`, `상품 범위 제외` 중 하나로 기록하며 이유 없이 빠진 파일이 있으면 완료로 보지 않습니다. 영카트 화면은 현재 상품 범위에서 제외하고 `theme.config.php`와 판매 설명에 명시합니다.

기본 데모 메뉴는 `페이지 유형 → #1~#5 패턴`의 3단 구조까지 표시합니다. 구매자는 `custom/navigation.php`에서 실제 사용할 패턴만 남기며 4단 이상의 임의 메뉴 엔진은 제공하지 않습니다.

### 5.1 하위 페이지 각각의 완성 레이아웃 선택권

형님의 2026-09-21 지시는 상위 메뉴별로 서로 다른 페이지 4~5개를 모으라는 뜻이 아닙니다. 출시 범위 확정에서 **기업개요 1~5, 인사말 1~5, 비전·가치 1~5, 연혁 1~5, 조직도 1~5처럼 하위 페이지 각각 5개 레이아웃**으로 통일했습니다. 사업 목록·상세·프로세스, 인재상·복리후생도 각각 같은 기준을 적용합니다.

기존 6분류 30종 제안은 집계 단위가 잘못되어 폐기했습니다. [확정 구성표](JW-BUSINESS-1.0-IMPLEMENTATION-SCOPE.md)는 메인 5·회사소개 35·사업영역 15·인재채용 10·고객센터 안내 5·연락처 안내 5, 합계 75개입니다. 같은 레이아웃을 여러 메뉴에 연결한 결과나 회사·사업 데이터만 교체한 결과를 중복 집계하지 않습니다. 카탈로그의 상위 메뉴·하위 페이지·패턴 구분은 사이트 3단 메뉴 추가를 뜻하지 않습니다.

색상·사진만 바꾼 복제 대신 같은 목적·내용을 서로 다른 섹션·레이아웃으로 표현하고, 버튼·아이콘·색상·G5 기능은 재사용합니다. 게시판 6개·최신글 8개 표현형과 FAQ·가입·1:1 문의 등 G5 기능은 별도 범위이며 75개 수량에 섞지 않습니다.

## 6. 메인 화면 구성

아래는 기업 종합형 메인의 구성 후보입니다. 메인은 기업 종합·사업 중심·프로젝트 중심·서비스/과정 중심·한 페이지 소개의 5종으로 설계합니다.

1. 풀 화면 히어로: 회사 가치 문장, 설명, CTA 최대 2개
2. 근거 수치: 설립연도, 프로젝트, 고객사, 기술·인증 3~4개
3. 사업영역: 선택 항목과 큰 이미지가 연동되는 아코디언
4. 대표 프로젝트: 사례 한 건을 크게 보여 주고 다음 사례로 연결
5. 핵심 역량·프로세스: 번호 목록과 선형 흐름
6. 기업 소식: 대표 기사 1개와 나머지 텍스트 목록
7. 문의 CTA: 전화·문의 페이지 등 명확한 전환 경로
8. 회사 정보가 포함된 푸터

같은 크기의 작은 카드가 섹션마다 반복되는 구성은 사용하지 않습니다.

## 7. 디자인 기본 방향

2차 시안 **Corporate Specification Folio**는 비교 후보였으며 최종 승인안이 아닙니다. 이후 3~6차 비교를 거쳐 2026-09-21 사용자가 실제 제작 착수를 지시했습니다. 6차를 출발점으로 실제 화면에서 조정합니다.

2026-09-21 [3차 PC 라이트 이미지 초안 5장](../../output/imagegen/jw-business-v3/README.md)을 생성했습니다. 큰 제목과 파노라마 사진, 세로 사업 선택 영역, 넓은 프로젝트 사례로 구성을 변경했습니다. 이미지 후보이며 아직 최종 방향이나 구현 토큰으로 승인되지 않았습니다.

- 흑연색과 밝은 미네랄 배경을 기본으로 청색 하나만 강조
- 실제 사람·공간·프로젝트 사진을 크게 사용하되 특정 산업 설비에 고정하지 않음
- 왼쪽 정렬 대형 문장, 근거 수치와 얇은 구분선
- 넓은 여백과 제한된 상호작용
- 과도한 둥근 카드, 유리 구체, 푸른 AI 이미지와 반복 등장 모션 배제

메인 1종을 먼저 구현·조정하고 목록·본문/댓글·쓰기·가입까지 같은 UI로 이어서 검토합니다. 실제 화면 확인 뒤 간격·서체·공통 UI 규칙을 확정합니다. 색은 DaisyUI의 라이트·다크 의미 색상 규칙을 유지합니다. 추가 이미지 승인을 제작 착수의 선행 조건으로 요구하지 않습니다.

## 8. 핵심 동작

- 데스크톱 1·2단 메가 메뉴와 모바일 전체 높이 드로어
- 최상단에서는 투명하고 아래 스크롤에서 숨었다가 위 스크롤에서 나타나는 헤더
- 최대 3장의 히어로 슬라이드, 자동 재생 정지와 모션 감소 대응
- 사업영역 이미지 연동 아코디언
- 포트폴리오 상세 이미지 확대
- 필요한 구간에만 짧은 진입 효과
- 공통 헤더의 라이트·다크 전환과 사용자 선택 저장
- 메인, 일반 페이지, 게시판, 댓글, 글쓰기, 로그인·가입·회원 기능, 검색·FAQ·1:1 문의와 테마가 담당하는 팝업까지 동일한 라이트·다크 상태 제공

스크롤 가로채기, 강제 부드러운 스크롤, 과도한 패럴랙스, 커서 추적 효과와 여러 배경 영상은 제외합니다.

색상은 daisyUI의 `corporate` 라이트와 `business` 다크 semantic token을 기준으로 사용합니다. 임의의 고정 배경색·글자색으로 전환을 우회하지 않습니다. 사용자 선택이 없을 때는 시스템 색상 설정을 따르고, 명시적으로 선택한 값은 브라우저에 저장합니다. 이미지 오버레이, 표, 에디터 출력, CAPTCHA와 G5 공용 UI도 두 상태에서 별도 확인합니다. G5 코어 관리자 전체 화면은 테마의 라이트·다크 범위에 포함하지 않습니다.

## 9. 데모 콘텐츠

데모는 **업종 중립적인 프로젝트 기반 기업**으로 시작합니다. 기술·건설·설계·전문 서비스·제품 기업으로 교체할 수 있게 사람, 공간, 프로젝트 결과를 함께 사용합니다. 첨단 제조·산업 이미지는 후보 중 하나이며 판매 자료와 시안 승인만으로 우월성이 입증되지 않았으므로 고정하지 않습니다.

필수 데이터:

- 회사명·슬로건·사업 설명이 서로 연결된 전체 문구
- 사업영역 3~4개와 서로 다른 상세 내용
- 프로젝트 6개 이상
- 뉴스·공지·자료실 각 5개 이상
- 연혁 8~12개, 인증·수상 6개 이상
- 조직도, 오시는 길, 문의, 채용공고
- 목록·상세·검색·빈 상태를 확인할 게시판 데이터

무작위 더미 문구와 관련 없는 이미지를 넣지 않습니다. 재배포 가능한 이미지·폰트·아이콘만 상품에 포함합니다.

## 11. 라이선스 기본안

- 라이선스는 구매한 회사 한 곳 또는 실명 개인 한 명에게 귀속됩니다.
- 귀속 주체가 직접 제작·운영하는 고객 사이트에는 수량 제한 없이 사용할 수 있습니다.
- 완성된 고객 사이트의 납품은 허용합니다.
- 구매 계정·업데이트 서비스 권한의 공동 사용·중고 양도를 제한합니다. 코드·자산의 재배포 조건은 LGPL 적용 코드·독립 제작 자산·외부 자산을 구분해 작성하며, 적용 라이선스의 권리를 일괄 금지하지 않습니다.
- 계열사·협력사·외주사와 라이선스를 공동 사용하지 않습니다.
- 구매 후 받은 버전은 계속 사용할 수 있으며 업데이트와 상품 결함 지원은 12개월입니다.

최종 판매 문구는 콘텐츠몰 약관과 기존 구매자 적용 범위를 확인한 뒤 확정합니다.

## 12. CS와 매뉴얼

필수 문서:

1. 5분 시작과 신규 설치
2. 기존 판매본 보관·`JW-Business 1.0` 별도 설치·원복
3. 메뉴·내용·게시판 연결
4. 로고·색상·폰트·이미지·문구 변경 위치표
5. 업데이트와 변경 이력
6. 증상별 문제 해결
7. 지원 범위와 문의 양식

## 13. 개발환경과 구현 승인 경계

- 개발 빌드는 Mac의 Bun workspace에서 수행합니다.
- 형님의 2026-09-20 지시에 따라 사무실 장비 `localubuntu`의 기존 서비스·포트를 확인하고 격리된 G5 기준 환경을 구축했습니다.
- `https://g5themes.test`는 호스트 Nginx 뒤의 `127.0.0.1:18085`로만 연결되며 MySQL은 Compose 내부 네트워크에만 둡니다.
- 기준 조합은 G5 5.6.391, PHP 8.3.33, MySQL 8.4.11이며 기존 Ubuntu PHP·MariaDB 컨테이너는 변경하지 않았습니다.
- 운영 서버용 설치 ZIP에는 Bun·Node·Docker가 필요하지 않습니다. 선택형 개발 키트는 로컬 Bun 1.4.2만 요구하며 서버를 설치하지 않습니다.
- 2026-09-21 형님의 명시적 제작 착수 지시를 반영해 로컬 테마 파일 생성을 시작했습니다. 실제 화면 검토와 Ubuntu 배포·시험 지시는 별도로 구분합니다.

구축 근거와 운영 경로는 [G5 로컬 검증 환경 구축 보고서](../reports/G5-LOCAL-RUNTIME-SETUP-2026-09-20.md)를 따릅니다.

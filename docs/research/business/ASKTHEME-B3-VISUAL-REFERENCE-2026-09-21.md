# ASKTHEME B3 — 기존 상품 화면 직접 검토

- 확인일: 2026-09-21
- 대상: [SIR 기존 상품 1499991844](https://sir.kr/contents-mall/items/1499991844)
- 방법: 로그인된 Microsoft Edge에서 상품 설명·변경이력과 PC·모바일 원본 화면 이미지를 확대해 육안 확인
- 목적: 제작자가 구현했던 콘텐츠 표현과 페이지 구성 원리를 JW-Business 1.0 기획에 참고
- 상태: 참고 조사 완료. 디자인 확정·구현·배포 지시로 취급하지 않음

## 1. 핵심 판단

기존 상품의 참고 가치는 **콘텐츠 성격별로 다른 최신글·게시판 표현을 준비하고, 이를 소개·사업·실적·문의 섹션과 조합하여 서로 다른 사이트를 구성한 것**에 있다. 기업형 메인 한 장뿐 아니라 커뮤니티형·협회형·포트폴리오형·원페이지에 각각 다른 정보 비중을 적용했다.

새 테마에서는 이 구성 원리와 기능별 표현의 다양성을 참고한다. 과거의 색상·서체·간격·장식·사진 배치나 구형 플러그인을 그대로 재현하지 않는다. **하나의 일관된 디자인 체계와 다양한 콘텐츠 레이아웃은 함께 제공할 수 있다.** 대표 디자인 하나라는 이유로 모든 최신글과 섹션을 같은 카드 형태로 축소하지 않는다.

이번 기록은 상품에 남은 화면의 관찰이다. 코드의 재사용 구조나 현재 실행 품질까지 입증하는 자료는 아니다.

## 5. 메인과 일반 페이지의 조합

근거: [메인 모음](https://sir.kr/data/editor/1808/3553042409_1533615233.0241.png), [하위 페이지 모음](https://sir.kr/data/editor/1806/3553042409_1528768843.8561.png), [변경이력의 원페이지 화면](https://sir.kr/data/editor/1808/3553042409_1535003895.5173.jpg).

### 메인

- **기업형:** 넓은 사진 히어로 → 회사·사업·미디어 안내 → 공지·고객센터·채용 등 정보 묶음 → 파트너 → 이미지와 설명 → 푸터.
- **커뮤니티형:** 사이드 로그인·공지·설문 등 보조 영역과 본문 최신글·갤러리·탭·배너를 조합. 기업형보다 게시물 탐색의 비중이 큼.
- **협회형:** 공지·후원 안내, 단체·활동·소식 이미지, 사진 갤러리·파트너를 조합.
- **포트폴리오형:** 영상 영역, 분류 필터와 이미지 격자, 별도 제품 갤러리, 파트너·소개 문구를 조합.
- **원페이지:** 히어로, 소개, 이미지·문장 분할, 수치·아이콘, 배경이 다른 소개, 서비스, 포트폴리오, 파트너, 지도·연락·문의 영역이 길게 이어짐.

원페이지는 같은 카드의 반복이 아니라 섹션별 정보에 따라 폭·배경·이미지 비율·정렬을 달리한다. 다만 정지 이미지로 스크롤 효과의 속도·연동·완성도를 판단할 수는 없다.

| 드로어 | 왼쪽 패널과 오른쪽 어두운 배경, 닫기·검색·하위 메뉴 표시·매뉴얼 링크 |

참고할 원칙은 **콘텐츠별 모바일 재배치**다. 소개는 읽기 좋은 한 열, 사진 탐색은 두 열, 메뉴는 계층 탐색과 검색을 갖춘 별도 패널로 구분되어 있다.

모바일 게시판 목록·상세·댓글·글쓰기·가입 화면, 실제 메뉴 열기·닫기, 스와이프, 화면 폭별 전환점, 키보드·포커스 동작은 미확인이다. 모바일 완성도 전체를 검증했다는 결론은 내리지 않는다.

## 8. JW-Business 1.0 기획에 반영할 기준

1. **시각 체계는 통일하고 콘텐츠 표현은 구분한다.** 공지·소식·사진·실적의 목적에 맞는 목록과 섹션을 검토한다. 과거 제공 수량을 그대로 새 상품의 확정 수량으로 삼지 않는다.
2. **메인과 일반 페이지에 같은 섹션을 조합할 수 있게 한다.** 정적 소개·사업·실적 섹션과 서버 데이터가 필요한 최신글 PHP 조합형의 사용 경로를 구분한다.
3. **섹션마다 모바일 규칙을 정한다.** 일괄 한 열 변환 대신 읽기·이미지 탐색·메뉴의 목적에 맞게 배치한다.
4. **재사용과 효과의 조합을 검증한다.** 섹션 중복·순서 변경, 슬라이더 복수 사용, 긴 제목·이미지 없음·빈 목록을 검수 후보로 남긴다.
5. **온라인 매뉴얼은 결과 화면과 수정 위치를 연결한다.** 구매자가 섹션·최신글 표현을 눈으로 고르고 정적 복사형과 PHP 조합형을 구분할 수 있게 한다.
6. **새 디자인 승인은 별도로 받는다.** 추가 시안에서 이 구성 원리를 현대적으로 표현하되 기존 디자인을 복제하지 않는다. 전 화면 라이트·다크 기준과 현재 확정 범위는 유지한다.

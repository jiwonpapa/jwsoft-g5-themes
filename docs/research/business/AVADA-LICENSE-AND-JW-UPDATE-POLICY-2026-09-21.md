# Avada·Divi 라이선스와 JW-Business 업데이트 정책 검토

- 조사일: 2026-09-21
- 상태: 공식 자료에 근거한 연구·권고안. 상품 설정·약관 적용·구현은 하지 않음
- 유지하는 사용자 결정: 기존 상품 교체, JW-Business 1.0, 구매자 귀속 무제한 사이트, 정상 39만원·출시 1개월 실제 판매가 29만원, 쿠폰 없음

## 1. 결론

현재 ThemeForest의 **Avada Classic은 1년 업데이트 상품이 아니다.** 사이트별 1회 구매에 향후 업데이트를 포함하고 기본 고객지원은 6개월이다. 무제한 사이트에 연간 업데이트·지원을 제공하는 비교 대상으로는 Divi 연간형이 더 가깝다.

JW는 **구매자 귀속 무제한 사용권 + 받은 버전 계속 사용 + 12개월 업데이트·상품 결함 지원**을 기본안으로 유지한다. 만료 후에도 받은 버전으로 새 고객 사이트를 제작할 수 있다는 점까지 판매 문구에 명시하는 것을 권고한다. 새 패턴과 지원 환경 대응이 업데이트의 가치가 되어야 한다.

단, SIR의 주기적 결제형 콘텐츠 금지와 기존 주문의 다운로드 권한을 확인하기 전에는 연간 갱신 상품을 판매할 수 있다고 확정하지 않는다. 선택적 연장권의 허용 여부와 가격은 미확정이다. 평생 업데이트·평생 개별 지원으로 확대하는 것도 현재 권고하지 않는다.

## 3. 많은 패턴을 제공하는 방식에서 가져올 점

Avada 판매 설명은 **110개 이상 완성 사이트, 650개 이상 Studio 콘텐츠 블록, 150개 이상 요소**를 서로 다른 단위로 안내한다. 각각을 모두 일반 페이지 패턴으로 세거나 합산하면 안 된다. 개발사 다른 페이지의 113개 사이트·600개 이상 블록 표기와도 집계 시점·단위가 다를 수 있다. [Avada 상품 구성](https://themeforest.net/item/avada-responsive-multipurpose-theme/2833226)

JW의 제공 구조는 다음처럼 유지한다.

1. 기업개요·인사말·비전·연혁·조직도 등 **각 하위 페이지에 완성 레이아웃 4~5개**를 제공한다. 서로 다른 하위 페이지를 합쳐 회사소개 5종이라고 세지 않는다.
2. 각 완성 페이지에서 사용한 섹션을 다른 제공 페이지에도 복사·조합할 수 있게 한다.
3. 하위 페이지별 미리보기, 패턴 번호, 필요한 자료, 적용 위치와 교체 예시를 온라인 매뉴얼에 제공한다.
4. 같은 제품에 새로 추가한 페이지·섹션은 업데이트 권한이 유효한 구매자에게 제공하는 것을 권고한다. 다른 업종의 별도 상품까지 모두 포함한다는 약속은 하지 않는다.
5. 출시 때 약속한 4~5개 패턴을 먼저 완성한다. 미완성된 약속을 다음 유료 연장의 혜택으로 넘기지 않는다. 매월 특정 수량의 추가를 약속하지 않는다.

모든 신규 패턴은 같은 색상·버튼·아이콘·섹션 계약과 PC·모바일·라이트·다크 검증을 따른다. 많은 패턴이 새로운 관리자 기능·페이지 빌더·플러그인 추가를 뜻하지 않는다. 구체 목록은 [하위 페이지별 패턴 조사](WORDPRESS-TOP-SELLERS-PAGE-VARIANTS-2026-09-21.md)를 따른다.

무제한은 **사이트 수**, 계속 사용은 **이미 받은 버전의 사용 기간**, 12개월은 **새 배포물과 문의 지원의 기간**으로 각각 명시한다. 만료되었다고 사이트를 멈추는 장치는 도입하지 않는다. 별도 인증 서버·도메인 등록 시스템은 현재 테마 범위에 추가하지 않는다.

### 지원 기간만으로 해외 상품보다 유리하다고 광고하지 않기

Envato의 지원에는 상품 사용법과 내장 기능 활용 질문이 포함된다. JW는 개인별 수정 안내를 매뉴얼로 처리하고 결함 지원에 집중하므로, 12개월과 6개월 숫자만 비교해 더 많은 지원이라고 표현하면 안 된다. [Envato 지원 범위](https://help.market.envato.com/hc/en-us/articles/208191263-What-is-Item-Support-and-what-s-included)

또한 Envato는 지원 기간과 상품의 중대한 보안 문제 대응을 구분한다. JW에서도 신규 패턴 접근·개별 문의 기간과 중대한 공통 결함의 공지·패치 배포 범위를 구별해 최종 정책에 적어야 한다. 이번 조사로 기존 12개월 정책을 평생 유지보수 약속으로 바꾸지는 않는다.

## 5. SIR 판매처 제약과 확인이 필요한 부분

공식 [판매자 약관](https://sir.kr/contents-mall/policies/seller-terms) 제10조①5는 **월별·연간 등 주기적 결제를 요구하는 구독형 콘텐츠**를 금지한다. 제10조②4는 플랫폼 밖 직접 판매와 유도를 금지한다. 따라서 외부 갱신 결제를 우회책으로 제안하지 않는다. 자동 결제가 없는 선택적 업데이트 연장권도 금지되는지는 공개 조항만으로 단정할 수 없다.

공식 [구매약관](https://sir.kr/contents-mall/policies/buyer-terms) 제9조④는 기본 보증기간 1년과 이후 무상 고객지원 종료를 안내한다. 이는 최신 파일 접근이 구매일로부터 자동 1년 제한된다는 뜻은 아니다.

실제 [현재 판매 상품](https://sir.kr/contents-mall/items/1789561911)과 [기존 등록 상품](https://sir.kr/contents-mall/items/1572497436)에는 결제 후 1년 다운로드·만료 후 버튼 비활성·연장 시 판매자 문의 안내가 있다. 반면 [구매자 가이드](https://sir.kr/contents-mall/buyer-guide)는 기간 제한이 없다고 설명한다. 개별 상품과 주문의 실제 설정을 확인해야 한다.

출시 전 다음 네 항목을 확인한다.

1. 기존 상품의 다운로드 기간을 변경하면 과거 구매분에도 적용되는가, 이후 구매분만 적용되는가.
2. 만료 후 모든 파일이 차단되는가, 구매 당시 파일의 재다운로드는 가능한가.
3. 같은 상품에서 구매 시점별 기존 파일·신규 버전 접근을 구분할 수 있는가.
4. 선택적 업데이트 연장권의 판매가 허용되는가. 허용된다면 실제 판매 옵션과 권한 연장 기능이 있는가.

**기존 판매 이력을 유지한 상품 교체 결정은 유지한다.** 기존 구매자의 다운로드 권한이나 사용권을 소급 축소했다고 가정하지 않는다. 기존 구매자에게 새 파일이 공개되는 조건과 지원 기준일은 별도로 명시해야 한다. 이번 조사는 공개 약관·상품 표시를 확인한 것이며 판매자 설정 변경이나 고객별 권한 시험은 하지 않았다.

## 6. 재판매 제한과 오픈소스 조건

G5의 공식 기본 라이선스는 LGPL 2.1이다. 공식 basic 전체를 복제해 시작하는 제품이므로, 파생 코드·독립 제작 자산·외부 라이브러리와 폰트·업데이트 및 지원 서비스를 구분해 라이선스를 작성해야 한다. 적용되는 LGPL 권리까지 일괄 금지하는 문구를 사용하지 않는다. 독립 제작 자산의 제한 가능 범위는 실제 파일 관계와 해당 자산의 라이선스를 확인한 뒤 정한다. [SIR G5 라이선스](https://sir.kr/gnuboard5/license), [공식 LICENSE.txt](https://github.com/gnuboard/gnuboard5/blob/master/LICENSE.txt)

사용자가 요구한 구매자 귀속·중고 판매 금지 의도를 판매 계정·서비스 권한·독립 제작물 중 어디에 적용할지 분리하는 작업이 필요하다. 테마 사용 고객의 사이트 납품과 원본 테마팩의 재판매도 같은 행위로 취급하지 않는다.

## 7. 가격과 사업적 판단

정상 39만원·출시 1개월 29만원 실제 가격 인하·쿠폰 미사용은 변경하지 않는다. 다만 해외에는 저가 단일 사이트 평생 업데이트 상품과 무제한 사이트 평생 플랜도 있으므로, **무제한이라는 조건만으로 가격 경쟁력이 입증되지는 않는다.**

JW의 구매 이유는 G5에서 필요한 회원·게시판 기능까지 일관된 UI, 국내 기업의 하위 메뉴별 여러 완성 페이지, 납품 시 재사용 가능한 섹션과 한국어 매뉴얼이 되어야 한다. 페이지 숫자만 Avada와 경쟁하는 전략은 권고하지 않는다.

연장 매출을 기본 수익으로 미리 계산하지 않는다. 선택적 연장이 허용되는 경우에 한해 별도 가격을 검토한다. 가격 결정권은 사용자에게 있으며 이번 조사로 갱신 요금을 확정하지 않는다. 실제 구매 전환율·지원 건수·반복 납품 수요가 검증되지 않았으므로 매출을 예측하지 않는다.

# AI 테마 난립기 의료통합 테마팩 29만원 판매 전략

- 작성일: 2026-09-20
- 분석 대상: 현재 SIR 콘텐츠몰 테마 카테고리와 의료 관련 상품
- 상품 가정: 그누보드5 의원·병원용 통합 테마팩, 290,000원 1회 결제
- 사용권: 구매 회사 또는 실명 개인에게 귀속, 허용된 사이트에 무제한 사용, 재판매·양도 금지
- 제공 기간: 기존 설치분 영구 사용, 호환성 업데이트·상품 결함 지원 1년
- 최종 판단: **기존 비즈니스 테마를 먼저 정상화해 재판매하고, 의료팩은 신규 상품으로 분리 출시**

## 결론

**형님, 새 의료통합 팩은 기존 테마를 수정하지 말고 신규 상품번호로 등록하는 것이 맞습니다.**

다만 기존 판매 중단 테마가 원래 기업·비즈니스 테마였다면 의료팩보다 먼저 정상 업데이트해 재판매하는 편이 유리하다. 기존 300건 이상의 판매 이력, 후기와 상품 페이지를 그대로 활용하면서 현재도 지원하는 판매자라는 신호를 다시 만들 수 있다. 이때 기존 구매자가 업데이트 파일을 내려받는 것은 같은 상품의 정상 업데이트이므로 감수하는 범위다.

기존 테마를 의료팩이나 전혀 다른 상품으로 바꾸지는 않는다. 기존 상품의 정체성을 유지한 디자인·모바일·호환성 개선은 같은 상품 업데이트로 보고, 구성과 용도가 달라지는 새 비즈니스 테마 또는 의료팩은 신규 상품으로 등록한다.

형님은 신규 판매자와 조건이 다르다. 사용자 제공 이력 기준으로 다른 앱과 판매 중단한 기존 테마가 각각 300건 이상 판매됐다. 이 수치는 이번 조사에서 공개 상품과 계정을 대조하지 않았으므로 시장 원자료에는 합산하지 않았다. 그러나 구매자가 판매자의 업데이트·지원 능력을 판단하는 강한 신뢰 자산이다.

2026-09-20 기준 SIR 테마 카테고리 검색 결과는 615개다. 이 중 2026년에 등록된 상품이 181개로 2025년 전체 88개의 2.1배다. 최근 60일에는 62개가 등록됐고 57개, 91.9%가 아직 판매 0건이다. 공급은 빠르게 늘지만 신규 상품 대부분은 판매를 만들지 못한다.

의료 관련 상품도 같은 흐름이다. 의료 키워드가 들어간 실제 테마·홈페이지 상품 27개 중 22개가 판매 0건이다. 2026년 신규 의료 상품 14개 가운데 13개가 0건이고 누적 판매는 전체 2건뿐이다. 반면 2020년 165,000원 의료 테마는 누적 82건, 2022년 165,000원 제품은 34건, 2024년 187,000원 제품은 14건을 기록했다. 의료 수요는 존재하지만 **신규 판매자보다 검증된 판매자와 제품군에 유리한 시장**이다.

따라서 29만원 패키지는 다음 조건에서 가능하다.

1. `의료 테마 여러 개`가 아니라 **과목별 화면과 서브페이지가 완성된 의료 테마팩**으로 판다.
2. AI로 쉽게 만들 수 있는 메인 시안·문구·색상 변형을 핵심 가치로 삼지 않는다.
3. 실제 의원 사이트 조사로 만든 과목별 메뉴, 완성형 서브페이지, 실제형 샘플 데이터와 설치 안정성을 판다.
4. 기존 상품의 다운로드 파일과 구매 권리를 건드리지 않고 **완전히 새로운 SKU**로 등록한다.
5. 다른 앱과 기존 테마의 300건 이상 판매 이력을 신규 상세페이지의 신뢰 증거로 연결한다.
6. 29만원은 상시 저가가 아니라 **패키지 출시가**로 운영하고 판매 데이터를 보고 정상가를 조정한다.

## 신규 상품으로 분리해야 하는 이유

기존 판매 중단 테마의 상품 파일을 의료통합 팩으로 교체하면 기존 구매자가 새 파일을 내려받을 가능성이 생긴다. 콘텐츠몰의 무제한 다운로드는 향후 업데이트 파일도 내려받을 수 있다는 의미이므로, 같은 상품번호에서 제품의 정체성과 라이선스를 바꾸면 권리 경계가 무너진다.

| 처리 방법 | 결과 | 판단 |
| --- | --- | --- |
| 기존 상품 파일을 의료팩으로 교체 | 기존 구매자가 신규 팩을 추가 결제 없이 다운로드할 수 있음 | 금지 |
| 기존 상품에 의료팩을 대규모 업데이트로 추가 | 과거 구매 범위와 신규 상품 범위를 구분하기 어려움 | 금지 |
| 원래 비즈니스 테마를 같은 용도 안에서 현대화해 재판매 | 300건 이상 판매 이력과 기존 구매권을 유지 | 먼저 진행 |
| 전혀 다른 새 비즈니스 테마로 교체 | 기존 구매자에게 새 상품이 무상 제공됨 | 신규 상품으로 분리 |
| 의료통합 팩을 새 상품번호로 등록 | 가격, 라이선스, 1년 업데이트와 구매자를 독립 관리 | 권장 |

새 상품 등록 시 다음을 분리한다.

- 새 상품명·상품번호·다운로드 파일
- 새 `LICENSE-KO.txt`와 고객 사이트 납품 규정
- 신규 구매일 기준 1년 업데이트 기간
- 신규 문의·변경 이력·지원 문서
- 기존 구매자에게 혜택을 줄 경우에도 새 상품을 구매하는 별도 업그레이드 정책

기존 상품 구매자에게 혜택을 주더라도 의료팩 파일을 기존 다운로드 영역에 넣지 않는다. 구매 증빙을 받은 뒤 새 상품 할인 또는 별도 구매 경로를 제공해야 권리가 섞이지 않는다.

### 판매는 기존 검증 상품에 집중된다

현재 전체 콘텐츠몰 상위권에는 77,000~99,000원대 범용 기업 테마가 많다. 퓨어화이트는 누적 430건, 다온 기업테마 business_#03은 338건, 테마크래프트 B는 309건이다. 이 상품들의 판매량은 수년에 걸친 누적값이므로 월 판매량으로 해석할 수는 없다. 다만 구매자가 새 시안보다 오랜 판매 이력, 후기, 설정 기능과 공급자 신뢰를 선택한다는 신호다.

형님은 이 시장에서 판매 이력이 없는 신규 판매자가 아니다. 사용자 제공 이력 기준으로 다른 앱과 판매 중단한 기존 테마가 각각 300건 이상 판매됐다. 따라서 최근 신규 상품의 0건 비율을 형님의 예상 판매율로 그대로 적용하면 과도하게 비관적이다. 새 상품 상세페이지에서 기존 상품명, 누적 판매 근거, 지원 기간과 업데이트 이력을 사실대로 연결해 판매자 신뢰를 이전해야 한다.

29만원 상품이 신규 등록 목록에 한 번 노출되는 것만으로 판매되기는 어렵다. 판매 페이지에 아래 증거가 필요하다.

- 실제 의료 사이트를 완성하는 전체 메뉴와 서브페이지
- 완성된 과목별 데모와 제공 파일 목록
- PC·모바일 실제 데모
- 설치, 업데이트, 복구 절차
- 지원 범위와 1년 업데이트 이력
- 제작사가 고객 납품에 사용할 수 있는 명확한 라이선스

### 2026년 저가 의료 상품의 난립

2026년에는 25,000~69,000원의 의료 원페이지·랜딩·업종 변형 상품이 짧은 기간에 다수 등록됐다. 9월 3일에는 같은 판매자가 업종별 BUSINESS#01~#20을 한 번에 등록했고, 그중 치과·한방병원·요양병원·안과의원 등 의료형 4개가 포함됐다. 9월 20일 관찰 시 의료형 4개는 모두 판매 0건이었다.

이 현상은 대량 템플릿 생산이 쉬워졌다는 직접적인 시장 신호다. 다만 목록만으로 개별 상품이 AI로 제작됐다고 단정하지 않는다.

## 3. AI 생산성이 바꾸는 경쟁

AI는 디자인 초안, 업종별 문구, 이미지, HTML·CSS 변형, 데모 데이터 생산 비용을 낮춘다. 그 결과 판매자 한 명이 여러 업종과 과목의 상품을 빠르게 등록할 수 있고, 구매자는 비슷한 화면을 더 많이 보게 된다.

### AI 시대에 가치가 빠르게 떨어지는 것

- 의료 이미지와 파란색·흰색 디자인
- 업종명만 바꾼 메인 화면
- 자동 생성한 소개·치료 문구
- 색상·배너만 다른 테마 수
- 페이지 수를 부풀린 반복 레이아웃

### AI 시대에도 돈을 받는 것

- 실제 의원 70~90개 사이트를 분석한 과목별 정보구조
- 의료진·질환·검사·치료·장비·비급여까지 연결된 전체 사이트
- 과목별로 준비된 완성형 샘플 데이터와 적용 문서
- G5 코어를 수정하지 않는 설치·업데이트·복구 구조
- 여러 PHP·G5 버전과 모바일에서 검수한 호환성
- 의료광고 위험 문구를 배제한 데모 콘텐츠 원칙
- 구매 회사·개인 귀속과 고객 납품 범위를 명확히 한 라이선스
- 실제 오류 수정과 1년 업데이트 이력

AI로 테마 생산 비용은 낮아져도 검수, 호환성, 법률 위험, 고객 지원 비용은 자동으로 사라지지 않는다. 의료통합 팩은 이 어려운 부분을 제품화해야 29만원을 방어할 수 있다.

### AI 시장 붕괴 대응책

시장은 사라지기보다 두 층으로 갈라질 가능성이 높다. 이미지·색상·업종명만 바꾼 상품은 더 싸지고 더 많이 등록된다. 반대로 구매 후 실제 사이트를 빨리 완성하고 장애 없이 납품하게 해 주는 제품은 판매자 신뢰와 운영 품질로 가격을 방어할 수 있다.

| 방어선 | 상품에 넣을 것 | 구매자에게 보여줄 증거 |
| --- | --- | --- |

## 6. 형님의 기존 판매 자산을 쓰는 방법

사용자 제공 이력 기준으로 형님에게는 세 가지 판매 자산이 있다.

기존 테마 구매자는 잠재 고객이지만 새 의료팩의 자동 구매자는 아니다. 새 상품을 별도 결제하게 하고, 혜택이 필요하면 기간·대상·가격이 명확한 유료 업그레이드 경로를 둔다. 기존 상품 다운로드에는 새 의료팩 파일을 넣지 않는다.

형님이 판매한 200만원 무제한 테마는 공개 판매·노출 가격이 아니라 개별 거래다. 따라서 콘텐츠몰 가격 비교표와 시장 중앙값에는 넣지 않는다.

이 거래는 다음 한 가지만 보여준다.

- 특정 고객은 충분한 필요와 신뢰가 있으면 무제한 사용권에 200만원을 지불한다.

거래 건수, 맞춤 범위, 지원 수준과 구매 동기가 확인되지 않았으므로 29만원 공개 상품의 반복 판매 가능성을 증명하지는 않는다. 다만 공개 상품에서 확보한 구매자를 설치·브랜딩·전용 과목 제작 같은 고가 서비스로 전환할 수 있다는 근거로는 유효하다.

## 9. 의료 분야 위험

의료법 제56조는 인터넷 의료광고에서 치료 효과를 오인하게 할 경험담, 거짓·비교·비방·과장 광고, 중요한 부작용 누락 등을 금지한다. AI가 생성한 치료 문구와 이미지를 데모에 바로 넣는 것은 상품의 신뢰를 높이는 대신 법률 위험을 키울 수 있다.

따라서 데모에는 다음 원칙을 적용한다.

- 치료 효과와 우월성을 단정하지 않는다.
- 후기와 전후 사진은 기본 비활성 또는 자리표시자로 둔다.
- 의료진 자격, 장비, 인증, 비급여 할인은 구매자가 사실 확인 후 입력한다.
- 데모 콘텐츠가 예시이며 의료기관의 사실 확인과 광고 검토가 필요하다고 표시한다.
- 증상·병력을 받는 상담 기능은 개인정보·민감정보 검토 전 기본 기능에 넣지 않는다.

## 최종 판정

**기존 비즈니스 테마 재판매를 먼저 진행하고, 의료팩은 신규 상품번호로 출시하는 조건부 GO다.**

현재 시장은 2026년 신규 상품 181개, 최근 60일 판매 0건 비율 91.9%로 공급 과잉 신호가 강하다. 의료 테마도 2026년 14개 중 13개가 0건이다. 다만 이것은 판매 이력이 없는 신규 상품의 위험을 보여주는 기준선이다. 앱과 기존 테마에서 각각 300건 이상 판매한 형님은 판매자 신뢰 면에서 유리하다.

그럼에도 기존 의료 테마가 16만5천~18만7천원에서 82건, 34건, 14건의 누적 판매를 만든 기록은 의료 수요가 실제로 있음을 보여준다. 29만원 의료통합 팩은 단품과 다른 수준의 과목 데이터, 전체 사이트 구성과 무제한 제작 사용권을 증명하면 판매할 수 있다.

성공 조건은 `많은 테마`가 아니라 **기존 판매 신뢰 + 조사된 의료 정보구조 + 완성형 화면 + 실제형 데이터 + 호환성 검증 + 독립된 새 상품 권리**다. 페이지 빌더나 별도 관리자 제작 기능은 이 상품의 범위가 아니다.

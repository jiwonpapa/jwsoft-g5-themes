# JW-Business 1.0 — 1·2·3차 시안 비교와 추천

- 검토일: 2026-09-21
- 대상: 각 차수의 메인·게시판 목록·본문/댓글·글쓰기·회원가입, 총 15개 PC 화면
- 추가 확인: 2차 모바일 메인·회원가입, 다크 게시판 캡처와 기존 QA 기록
- 산출물: 비교·추천 보고서. 시안 수정, 테마 구현, 배포는 수행하지 않음
- 상태: **2차를 대표 방향으로 추천. 사용자 디자인 승인은 아직 없음**

## 1. 결론

**JW-Business 1.0의 대표 메인과 섹션 구성 방향은 2차를 추천한다.** 사진형 사업 소개, 실적 띠, 비대칭 사례, 아이콘 역량, 과정, 최신글이 서로 다른 형태로 이어져, 구매자가 가져다 쓸 섹션의 종류를 가장 잘 보여 준다. 이는 다수의 일반 페이지와 재사용 섹션을 제공한다는 상품 목적에 부합한다.

게시판·글쓰기·회원가입의 기본 배치는 **3차의 간결한 구조가 더 적합하다.** 2차의 색상·서체·아이콘·버튼 규칙을 공통 기준으로 삼고, 기능 화면에서 큰 배너와 불필요한 보조 칼럼을 줄이는 방향을 권고한다. 서로 다른 시안의 색·버튼을 화면별로 복사하자는 뜻은 아니다.

1차는 편집형 회사소개·포트폴리오에 맞는 선택 패턴으로 가치가 있다. 3차의 제목과 사진을 분리한 메인도 간결한 기업 소개 패턴 후보로 보존할 만하다. 채택 여부와 75개 페이지에 대한 실제 배정은 승인 후 결정한다.

## 2. 판단 기준과 증거 한계

현재 확정된 [출시 범위](../plans/JW-BUSINESS-1.0-IMPLEMENTATION-SCOPE.md)의 메인 5종·일반 페이지 70종, 섹션 재사용, G5 기본 기능, 전체 라이트·다크 요구를 기준으로 비교했다.

평가의 우선순위는 ① 서로 다른 섹션의 구성과 재사용 가능성 ② 기업 콘텐츠의 전달력 ③ 게시판·입력 화면의 집중도 ④ 공통 UI의 일관성이다. 구현 증거는 시각적 우열과 별도로 평가했다. 판매량·전환율·CS 감소 효과를 측정한 결과는 아니므로 수치 점수나 매출 예측을 붙이지 않는다.

- 1·2차는 HTML/CSS로 렌더링한 시안이며 실제 G5 연동 화면이 아니다.
- 3차는 생성 이미지다. 색상 토큰·실제 폰트·아이콘·반응형 동작의 구현 증거가 아니다.
- 이미지 해상도와 전체 길이가 달라 자동 축소된 글자 크기만으로 가독성을 판정하지 않았다. 정보 순서·배치·표현 위계를 중심으로 판단했다.
- 2차의 기존 QA는 당시의 정적 캡처 검사다. 이번에 폼 제출·G5 연동·모션을 재검증하지 않았다.
- 어느 시안도 75개 레이아웃 전체의 다양성이나 섹션 복사 후 동작을 입증하지 않는다.

## 4. 화면별 판단

### 메인: 2차 추천

2차는 사진 히어로 → 바로가기 → 사업 사진 → 짙은 실적 띠 → 높이가 다른 프로젝트 → 아이콘 역량 → 사진과 과정 → 대표 소식과 목록 순으로 화면의 리듬이 달라진다. 구매자가 사업 소개·사례·실적·과정 등을 독립 섹션으로 이해하기 쉽다.

1차의 편집형 구성은 개성이 있지만, 메인에서 보여 주는 정보의 종류와 배치 변화가 비교적 적다. 3차는 큰 제목과 파노라마를 분리한 첫 화면이 좋고 사진 교체 시 문구 대비를 관리하기도 유리하다. 다만 메인 전체를 비교하면 2차 쪽이 테마팩에 포함될 여러 표현 방식을 더 잘 보여 준다.

2차 역시 전형적인 기업 사이트 문법을 사용한다. 독창성이 이미 충분하다고 평가하지 않는다. 사진 3개의 반복, 산업 편중, 익숙한 중앙 제목과 아이콘 열은 보완 대상이다.

### 게시판 목록: 기본형은 3차 추천

3차는 제목·검색·분류·게시물·페이지 이동을 곧바로 파악할 수 있다. 2차는 큰 교량 배너 아래 하위 메뉴와 게시판 분류가 겹쳐 등장해 목록까지의 이동이 길다. 1차는 대표 글 사진을 먼저 크게 보여 주므로 일반 공지보다 웹진형에 적합하다.

3차의 선택 체크박스와 선택삭제는 관리자 권한을 표현한 예시인데, 헤더에는 로그인이 표시된다. 실제 권한 상태에 맞게 분리해야 한다. 간결한 배치를 권고하는 것이 화면의 권한 구성을 그대로 승인한다는 뜻은 아니다.

### 게시판 본문·댓글: 기본형은 3차, 편집형은 1차

3차는 제목·작성 정보·본문·첨부·조작·댓글·이전/다음 글의 관계가 명확하다. 기본 게시판의 출발점으로 적합하다.

1차는 좁은 본문 폭과 인용문·소제목의 위계가 좋아 장문 기사형에 활용할 수 있다. 2차는 상단 배너, 하위 메뉴, 우측 목차·관련 사업 안내가 본문과 함께 등장한다. 간단한 공지나 짧은 글에도 이 구성을 기본 적용하면 과하다. 목차 자동 생성 등 별도 기능을 추가하는 근거로 사용하지 않는다.

### 글쓰기: 3차의 구조 추천, G5 설정 연결은 별도 확인

3차는 분류·제목·본문·파일·링크·CAPTCHA를 그룹별로 정렬해 작성 경로가 명확하다. 2차의 상단 배너와 좌측 기본 정보/본문/첨부 메뉴는 짧은 단일 폼에서 차지하는 면적에 비해 효용이 작다. 1차도 단일 폼 흐름은 좋지만 큰 제목과 바깥 여백이 길다.

3차의 파일 2개·10MB·글자 수 예시는 고정 상품 규칙으로 채택하지 않는다. G5 설정에 따른 표시가 필요하다. 이미지 속 에디터는 신규 에디터 개발 범위를 뜻하지 않는다. 모바일에서는 좌측 레이블을 필드 위로 옮기는 등 별도 배치 검토가 필요하다.

### 회원가입: 3차의 집중도 추천

3차는 계정 정보·회원 정보·추가 설정이 명확하고 사진 홍보 영역이 없어 입력에 집중하기 쉽다. 2차는 계정/회원 정보의 구분과 주 버튼이 좋지만, PC 좌측의 교량 사진과 홍보 문구는 가입에 필요한 정보가 아니다. 기존 모바일 캡처에서는 이 보조 칼럼이 빠져 더 간결해진다.

1차는 단계 표시와 단일 폼이 명확하지만 2열 입력·넓은 여백·비밀번호 강도 표시 등이 섞인다. 3차의 필수 항목·비밀번호 조건도 G5 실제 설정과 대조해야 한다. 어느 이미지에서 항목이 빠져 있다고 해서 상품에서 그 기능을 제외하지 않는다.

## 5. 2차를 기준으로 삼을 때 필요한 보완

1. **사진 반복을 줄인다.** 같은 공장·인물·교량을 사업·프로젝트·과정·소식에 반복 배치한 상태는 상품 대표 데모로 부족하다. 동일한 가상 기업의 사업과 연결된 서로 다른 장면이 필요하다.
2. **기능 화면의 장식을 줄인다.** 공지·본문·쓰기에는 작은 페이지 제목을 기본으로 두고, 가입은 입력 중심으로 정리한다. 큰 배너는 기업 소개나 사업 안내 등 목적에 맞는 페이지에서 사용한다.
3. **한 UI 규칙을 유지한다.** DaisyUI corporate/business, Pretendard, Lucide, 버튼 위계·필드·표·댓글 규칙은 공통으로 둔다. 3차의 파란 픽셀이나 버튼 모양을 그대로 별도 팔레트로 복사하지 않는다.
4. **다크의 구분감을 확인한다.** 2차 다크 목록 캡처에서는 검색창 경계와 행 구분선이 배경에 약하게 보인다. 이번에는 대비 수치를 측정하지 않았으므로 접근성 실패로 단정하지 않으며, 실제 컴포넌트 확정 때 확인한다.
5. **다양성은 배치로 증명한다.** 제목·사진만 바꾸는 방식으로 5종을 채우지 않는다. 회사소개 하위 유형마다 정보 순서·열 구성·사진 비중·표현 방식의 차이를 비교해야 한다. 버튼이나 아이콘 규칙을 바꾸어 차별화하지 않는다.

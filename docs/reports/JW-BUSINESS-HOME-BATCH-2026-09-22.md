# 메인 2~5 메뉴 묶음 구현 결과

2026-09-22 · JW-Business · 메뉴별 일괄 구현 목표의 첫 디자인 묶음

## 결과

`index_2.php`~`index_5.php`의 스캐폴드를 독립 완성형 본문으로 교체했습니다. 공용 head/tail과 허용된 공용 메뉴 외에 본문 partial·renderer·dispatcher를 만들지 않았습니다. `index.php`가 기본 홈이며 원하는 파일을 복사해 교체합니다. 대안 파일은 같은 본문을 직접 미리 볼 수 있습니다.

| 홈 | 중심 구성 | 목적에 맞는 동작 |
| --- | --- | --- |
| 2 | 사업 설명, 업무 범위 행, 사례 명세, 회사 소개 | 사업별 내부 이동·상세 링크 |
| 3 | 대표 사례, 크기가 다른 프로젝트 사진, 관점 설명 | 사례별 상세 이동 |
| 4 | 단계형 도입, 산출물, 협업, FAQ | native details 펼침 |
| 5 | 큰 사진, 회사, 사업, 사례, 연락처 | sticky 내부 목차·전화·이메일·문의 |

기존 jw-light/jw-dark·Pretendard·공용 버튼을 유지하고 읽기 순서를 구분했습니다. 복사 사용한 CTA와 로고에는 `blocks/` 원본 경로와 독립 복사 주석을 남겼습니다. 기존 구조 개편 중 생긴 로고 sprite 전체 노출을 PC·모바일 head/tail에서 함께 수정했습니다. 긴 개발 메뉴는 화면 안에서 스크롤됩니다.

## 검증 증거

- 테마 `bun run check`: 구조·token·타입·build·37 tests·build 검사 통과. 219 assertions.
- 저장소 루트 `bun run check`: 계약·token·scaffold·ZIP 회귀 검사 통과.
- 실제 Ubuntu PHP 8.3: 홈 1~5와 PC·모바일 head/tail 9파일 lint 통과.
- 실제 G5 브라우저: 새 홈 4종 × 360/390/768/1440px × 라이트/다크 32조합. HTTP 200, h1 하나, 본문 가로 넘침·누락 아이콘·broken img·pageerror 없음.
- 대표 PC 라이트/모바일 다크 전체 화면 8장 시각 확인. 근거 경로 `output/playwright/menu-batches/home-{2,3,4,5}-{desktop,mobile}.png`와 `home-matrix.txt` (로컬 결과, Git 제외).
- 실제 파일 교체: 홈 2~5를 차례로 `index.php`에 복사하여 루트 PC·모바일 8경로의 본문/PHP 오류 여부 확인. 검사 후 기존 기본 홈 복원.
- 본문 내부 사이트 링크 11개 HTTP 200/PHP 오류 없음. 비회원 온라인 문의는 로그인 안내, 회원 로그인 후 PC·모바일 8개 홈의 내 정보/로그아웃 shell과 실제 문의 목록 확인 후 로그아웃. 회원 검사는 HTTP이고 회원 화면 시각 검수를 의미하지 않습니다.
- 모바일 메뉴의 회사소개 펼침·메인 5 이동, 홈 4 FAQ 펼침, 홈 5 연락처 앵커·설정값 기반 tel/mailto 확인.
- Impeccable 독립 검수의 수정 요청 2건(홈 3 전체 사례 시연 표시, 홈 2 모바일 사업명 띄어쓰기)을 수정했습니다. 재검수 `ship`은 해당 2건의 해결 확인 범위이며 전체 테마 출시 승인으로 확대하지 않습니다.
- 수동 디자인 감지 결과는 빈 목록이었습니다. 기존 디자인 체계와의 비교·문서화를 마쳤으며, [메인 디자인 기록](../../themes/business/jw_business/docs/HOME-VARIANTS-DESIGN.md)에 실제 규칙과 남은 기존 문서 drift를 구분했습니다.

## 개발 반영·복구

사용자 승인 범위의 기존 `g5themes.test` 테마와 `/pages/`만 반영했습니다. 운영 사이트·G5 코어·DB 스키마·서버 설정은 변경하지 않았습니다.

구조 반영 전에 서버 `backups/before-menu-batches-20260922.tar.gz`로 테마와 pages를 보관했습니다. 폐기된 런타임 partial·테마 내부 페이지 경로는 이 백업에서 복구 가능합니다. 빈 공식 메뉴 테이블에 개발 탐색용 83개 메뉴를 추가했습니다. 이후 fixture는 기존 메뉴를 보존하고 건너뜁니다.

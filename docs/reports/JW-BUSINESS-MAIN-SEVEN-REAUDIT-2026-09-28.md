## 6. 개선 지시가 충분히 반영되지 않은 이유

현재 하네스는 누락·깨짐·일부 정렬을 찾는 데 도움이 되지만, 다음 한계가 확인됩니다.

1. **아이콘 누락 검사가 아이콘 활용 검사는 아닙니다.** `missingIcons`는 변환되지 않은 아이콘 표식을 찾습니다. 서비스형처럼 아이콘을 아예 작성하지 않은 페이지도 0으로 통과합니다.
2. **영역 존재 검사가 시각 자료의 품질을 보장하지 않습니다.** `결과물 시안`이라는 선택자가 있어도 내용이 큰 글자와 목록뿐이면 사용자의 요구를 충족하지 못합니다.
3. **이미지 수집 경로가 분리돼 있습니다.** UI 검사 `media`는 `document.images`만 수집해 메인2의 CSS 배경 3장을 놓칩니다. 소스 품질 검사는 CSS 배경을 별도로 다루지만 렌더링 증거 목록도 일치시켜야 합니다.
4. **상태를 고려하지 않은 검사는 실제 결함과 오탐을 섞습니다.** 쇼케이스 탭 문제가 이에 해당합니다.
5. **하네스 도입 완료와 제품 디자인 개선 완료를 구분해야 합니다.** 서비스·공간·메인3은 자동 검사 4개 상태가 통과해도 시각적으로 보강할 부분이 있습니다. 반대로 쇼케이스의 탭 가시성 실패는 제품 누락이 아닙니다.

# JW-Business 모바일 메뉴 개선 결과

2026-09-22. 사용자 개선 지시에 따라 테마 원본을 수정하고 기존 `g5themes.test` 개발 환경에 반영했습니다. 코어·DB·추가 라이브러리 변경은 없습니다.

## 변경

- 좁은 드로어와 2중 아코디언을 전체 화면, 고정 대분류, 선택 분류의 단일 아코디언으로 교체.
- 닫기/대분류/하단 문의는 하위 목록을 스크롤해도 남습니다. 화면 safe area와 높이 변화에 대응합니다.
- 회사소개 패턴 35개를 유지하고 같은 주소의 전체 보기/대표 패턴 8개를 제거. 독립된 상위 목적지는 안내 링크로 보존.
- 기존 모바일 메뉴의 고유 목적지 77개가 모두 유지됩니다. 비회원 회원가입/회원 내 정보 링크가 추가되어 각 상태에서 78개입니다. 별도 PHP 렌더 비교로 누락 0개 확인.
- 3단 패턴 링크는 48px 이상, 유형과 대분류는 56px 이상. 현재 페이지는 배경/굵기/밑줄과 `aria-current`로 표시하고 소속 분류·유형을 처음부터 엽니다.
- 헤더에 보이는 ‘메뉴’ 글자와 ‘문의’ 링크 추가. 모바일 화면 모드 전환은 열린 메뉴의 보조 기능으로 이동.
- 배경 스크롤 잠금/복원, Escape, 포커스 복귀, 첫·마지막 컨트롤의 Tab 순환, PC 폭으로 전환할 때 닫기를 처리.
- 모든 대분류가 단순 링크인 사용자 메뉴는 빈 오른쪽 패널 없이 한 열로 표시하도록 처리. 이 사용자 설정 분기는 실제 고객 설치 시험 전입니다.

## 확인한 증거

- 테마 `check`: 20 tests, 118 assertions, typecheck/build/산출물 검사 통과. CSS gzip 30,047 bytes, JS gzip 10,220 bytes.
- 수정 PHP 문법, `git diff --check`, 수동 Impeccable 감지 통과.
- Edge의 실제 G5 모바일 진입(`?device=mobile`), 관리자 로그인 상태에서 확인.
- 320×700, 390×844 실제 화면 확인. 360/390/768px 폭에서 메뉴 폭과 가로 넘침 없음 실측. 라이트/다크 모두 확인.
- 기업개요 #2 링크로 실제 이동한 후 회사소개·기업개요 자동 열림과 정확한 현재 링크 표시 확인.
- 사업분야로 전환, 하위 유형 한 개 열림, Escape 닫기, 닫기↔문의하기 키보드 순환 확인.
- 내부 스크롤 110.5px 상태에서도 닫기 top 15.5px, 첫 대분류 top 92px 유지.
- 본문 열림 시 저장한 스크롤 243.5px가 닫은 뒤 243.5px로 복원됨. 최상단 0px 복원도 확인.
- 최초 키보드 검증에서 네이티브 dialog만으로 역방향 Tab이 브라우저 영역으로 나가는 것을 발견해 명시적 순환을 추가했고 재확인했습니다.

## 남은 검증

실제 휴대전화 Safari/Chrome, VoiceOver/TalkBack, 200% 확대, 기기 뒤로가기와 가상 키보드 조합은 이번에 검증하지 않았습니다. 비회원 메뉴는 PHP 렌더 비교이며 실제 비회원 브라우저 로그인 흐름을 새로 시험한 것은 아닙니다. 사용자 비교 실험 전이므로 ‘최적의 메뉴가 입증됐다’고 주장하지 않습니다. 판매 ZIP 설치·업데이트 시험도 별도입니다.

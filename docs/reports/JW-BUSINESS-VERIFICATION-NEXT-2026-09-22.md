# JW-Business 재검증 및 다음 작업

2026-09-22 실제 https://g5themes.test 에서 Edge로 검증했습니다. 이번 판정은 **검색 정렬 개선 통과, 전체 테마 완료 아님**입니다.

## 이번 실행 증거

| 검증 | 결과 |
|---|---|
| 전체검색 실제 검색 | 서비스 검색 후 152건·16페이지 표시 |
| 검색 페이지 이동 | 다음 클릭 → 11페이지, 처음·이전·12~16페이지 표시 |
| 전체검색 390px | 입력/버튼 48px, 상단 좌표 동일, 가로 넘침 없음 |
| 공지 게시판 실제 mobile 스킨 | device=mobile로 확인. 검색 펼침 정상 |
| 게시판 검색행 | 모바일에서 버튼이 별도 줄에 있던 배치를 입력 옆으로 수정하고 빌드·개발 사이트 반영 |
| 수정 후 게시판 검색행 390px | 입력/버튼 높이 48px, 상단 각각 528.53125px, 차이 0px, 가로 넘침 없음 |
| FAQ 320px 다크 | 입력/버튼 높이 48px, 상단 각각 215.328125px, 차이 0px, 가로 넘침 없음 |
| FAQ 답변 | 첫 질문 클릭 후 답변 펼침 확인 및 스크린샷 직접 검토 |
| 콘솔 | 검증 탭에서 수집된 error 없음 |
| 수정 후 테마 check | 토큰·타입·빌드·산출물 검사 및 26개 테스트/135 assertion 통과 |

이번에는 계정 생성, 게시물 저장·삭제, 외부 인증 및 ZIP 설치 시험을 실행하지 않았습니다. 외부로그인·인기검색어는 이전 구현 상태이며 별도 배치 화면 검증은 남아 있습니다. 브라우저 라이트모드·PC 기기 선택 및 크기 override를 복원하고 검증 탭을 닫았습니다.

## 발견된 문제와 다음 순서

1. **최우선: 관리자 모바일 게시판 목록** — 직접 본 화면에서 행 선택 체크박스와 분류 배지가 겹칩니다. 선택 영역을 콘텐츠와 분리하고 공지·자유·갤러리에서 관리자/일반회원/비회원, 320/390/768/1440px를 확인합니다. 검색 정렬 개선과 별개의 남은 문제입니다.
2. **회원 폼·위젯 검증 완료** — 회원가입 주소 입력/검색 버튼, 로그인·비밀번호 찾기, 외부로그인 회원/비회원, 인기검색어 유무를 확인합니다. 일반 회원 계정과 가입 완료 여부는 별도 증거가 필요합니다.
3. **남은 레거시 제거** — 배포 payload 검색에서 jQuery 관련 코드가 남은 6개 파일: PC/모바일 설문 결과 2개, 회원 인증 갱신 2개, 최신글 notice 2개. PC notice도 탐지되었으므로 모바일 캐러셀만 남았다고 축소하지 않습니다. 실제 호출·주석 여부와 대체 기능을 개별 확인한 후 수정합니다. 본인인증은 외부 서비스 설정 없이는 실연동 완료로 판정하지 않습니다.
4. **기본 기능 통합 회귀** — 작성/수정/답변/댓글/첨부/페이징/권한과 다크·라이트를 검증합니다. 데이터 삭제·외부 전송 없이 가능한 검사와 실제 상태 변경 검사를 분리합니다.
5. **일반페이지·섹션 디자인 개선** — 기본 기능 잔여 결함을 정리한 뒤 Enfold 비교 보고서와 확정 기획을 따라 기업개요 5종의 구성 차이·여백·이미지·효과를 개선합니다. 동형 페이지 양산을 완료로 보지 않습니다.

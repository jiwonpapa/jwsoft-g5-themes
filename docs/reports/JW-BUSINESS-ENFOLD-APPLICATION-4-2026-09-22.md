# Enfold 연구 적용 4차 — 기업개요 #4 사례형

## 실제 반영

https://g5themes.test/pages/company-overview-4.php

비대칭 모자이크와 사업 행 구조는 유지했습니다. 기존 사례의 추상적인 설명과 관련성이 약한 외관 사진을 다음 구조로 교체했습니다.

- 가상 워크플레이스 사례: 대상/과제/참여 관점을 짧게 명시.
- 문제 정의: 대화와 집중 업무가 충돌하는 상황을 구체화.
- 검토 항목: 업무 장면 → 배치 검토 → 운영 기준. 각 펼침 항목에 남기는 자료 표시.
- 결과물 예시: 입구·라운지·회의·집중 영역의 관계를 HTML/CSS 개념도로 표현.
- 배치/운영/이후 확인 기준과 연결.

실제 시공 도면이나 실적이 아닌 예시임을 표시했습니다. 기존 보유 사진 사용이며 신규 사진이나 실제 고객 사례를 확보한 것은 아닙니다. 기존 하드코딩 갤러리 링크는 해당 사례 구간에서 제거했습니다. 사업 상세 링크 목적지의 본문 완성은 별도 남은 작업입니다.

## 검증

- 테마 check 통과: 26 tests / 135 assertions, 토큰·타입·빌드·산출물 검사.
- 서버 PHP 8.3 페이지 문법 검사 통과.
- 기존 개발 사이트에 payload 반영. 코어·DB 변경 없음.
- PC 1440px 라이트: 결과물 개념도와 본문 직접 시야 확인.
- 두 번째 검토 항목 클릭: 설명과 남기는 자료 펼침 확인.
- 모바일 390px 다크: 전체 흐름 시야 확인, 개념도 너비 335px, 문서 가로 넘침 없음.
- 모바일에서는 도식이 아래로 이동하므로 '오른쪽' 설명을 위치 독립적인 문구로 수정 후 재빌드/반영.
- 실제 사례 자료 검증, 모든 화면/회원 기능, ZIP 설치 검증 완료를 의미하지 않음.

## 원본·기술 스택·출처

- 독립 PHP와 G5 메뉴·게시판·최신글 구조를 유지했습니다. G5 코어, DB, 다른 메뉴 PHP는 수정하지 않았습니다.
- 편집 원본은 `src/php/`, 독립 `pages/`, `src/styles/`, `src/scripts/`입니다. Tailwind 4·daisyUI·DTCG의 `jw-light/jw-dark`와 Vite 빌드를 사용합니다. 생성된 `theme/`를 직접 수정하지 않았습니다.
- 이번 5개 CSS 원본의 고정 UI 색상을 의미 토큰으로 치환했습니다. 색 변수 사용만으로 검증을 끝내지 않고 라이트·다크의 실제 글자와 도형 대비를 다시 확인했습니다.
- 큰 아이콘은 Lucide, 슬라이더는 Embla, 스크롤 연출은 Motion을 사용합니다. hover/focus와 동작 줄임은 CSS·브라우저 설정을 사용합니다. 새 라이브러리를 추가하거나 버전을 바꾸지 않았습니다.
- 새 래스터 5장의 정확한 프롬프트·참조 이미지는 [자산 기록](../../themes/business/jw_business/docs/MAIN-SEVEN-ASSETS-2026-09-28.json)에 있습니다. 출처 sidecar는 개발 원본에 보관하고 상품 payload에서는 제외합니다. NODE의 옛 소스는 보관하되 프레임 36장·포스터는 빌드 payload에서 제외했습니다.
- [편집·디자인 인계](../../themes/business/jw_business/docs/MAIN-SEVEN-DESIGN-HANDOFF-2026-09-28.md)에 페이지별 책임, CSS/JS 연결, 자료 교체 방법과 제약을 정리했습니다.

# Enfold 연구 적용 3차 — 기업개요 #3 현장형

## 반영 결과

https://g5themes.test/pages/company-overview-3.php 에 반영했습니다. 이번 완료 범위는 #3 개선이며 #4~5 및 전체 테마 완료가 아닙니다.

Enfold 연구의 사진 역할 구분과 전폭/설명 구간의 리듬 변화를 적용했습니다.

- 외관 전폭 히어로 → 세 장면 목차.
- 접근 동선: 큰 제목과 관찰 내용/질문으로 구성.
- 업무 공간: 전폭 사진 아래 대화·집중·전환의 관찰 내용을 짧게 배치.
- 공동 검토: 인물/도면 사진과 검토 질문, 기록 방식의 편집형 배치.
- 마지막 문의 CTA는 실제 1:1 문의 경로 연결.

반복하던 외관 사진을 제거해 페이지 내 외관·업무 공간·협업 사진을 각 한 번 사용합니다. 보유 사진을 재구성한 것이며 새 현장 사진 세트를 확보한 것은 아닙니다. 사진·질문은 예시임을 명시했습니다. #1의 단계 목록, #2의 비교표를 복제하지 않았습니다.

## 검증 증거

- 정식 theme check: 26 tests, 135 assertions, 토큰·타입·빌드·산출물 검사 통과.
- Ubuntu PHP 8.3: 페이지 문법 검사 통과.
- 기존 개발 사이트 payload 반영. G5 코어/DB 변경 없음.
- Edge 1440px PC: 목차의 '02 머무는 환경' 클릭 후 #company-workplace 이동, 전폭 사진·설명 구간 직접 시야 확인.
- PC 스크롤 전/후 패럴랙스 값 변화 확인: 외관 0.6→48px, 업무 공간 -48→13.2px.
- 390px 모바일 다크: 전체 페이지 시야 확인, 문서 가로 넘침 없음, 두 사진 이동값 모두 0px.
- PC prefers-reduced-motion=reduce: 두 사진 이동값 모두 0px 확인.
- 검증 후 미디어/뷰포트 override 및 라이트모드 복원.

7개는 첫 화면의 주인공, 중간 자료의 형태, 길이와 읽는 순서를 다르게 만들었습니다. 메뉴명도 목적이 드러나도록 바꾸었고, 실제 G5 DB 메뉴 7개를 이름만 변경했습니다. 변경 전 DB는 Ubuntu `backups/main-seven-menu-before-20260926.json`, 파일은 `backups/main-seven-pre-20260926.tgz`에 보관했습니다. 원페이지 PHP 3개는 상품 웹루트 `pages/`로 옮기고 CSS/JS를 빌드해 `theme/` payload에 넣었습니다. 이전 서비스·프로젝트 원페이지에서 다른 메인의 사진을 복사한 두 파일은 제거했습니다. 원페이지 검사에는 파일명뿐 아니라 원본 해시를 비교해 메인 사진의 복사·이름 변경을 차단했습니다. 가상 제품·공간·사례는 실제 실적이나 완공 프로젝트가 아니라고 화면에 밝혔습니다.

내장 브라우저에서 7개 첫 화면과 대표 중간 장면, PC 라이트·다크 및 390px 모바일을 직접 확인했습니다. #4의 네 산출물과 프로젝트의 서로 다른 갤러리 이미지를 추가 확인했습니다. 8개 주소(기본 홈 포함) × PC/모바일의 HTTP·PHP·메뉴 검사, 원페이지 배포 자산 46개의 내용 해시 비교가 통과했습니다. 브라우저 시야에서는 각 목적이 구분되지만, 전체 화면 16장과 여섯 쌍의 독립 비교 기록은 아직 없습니다.

`bun run build`, `structure:check`, `check:build`, `typecheck`, `tokens:check`, 테마 테스트 63개, `contracts:check`, `tooling:test` 10개, 원페이지 harness 15개가 통과했습니다. `quality:check`는 실패했습니다. 홈 #1·#3·#4의 설계 준비 플래그와 홈 독립 검토 자료가 미완성이며, 다른 메뉴의 일반 페이지 16개도 설계·검토, 반복 도입, 디지털 결과물, 사진 재사용 문제를 남겼습니다. 이번에 손댄 메인 4종의 사진 사용 목록에는 교차 재사용이 없습니다. 이 실패를 예외 처리하거나 품질 차단을 완화하지 않았습니다.

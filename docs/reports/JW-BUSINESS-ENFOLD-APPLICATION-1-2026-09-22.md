# Enfold 연구 적용 1차 — 기업개요 #1

## 실제 구현·반영

사용자의 일반페이지 진행 지시에 따라 잔여 레거시 전체 완료를 기다리는 순서를 변경했습니다. 기존 기능 잔여 검증은 유지하되 일반페이지를 별도 단위로 구현합니다. 이번 대상은 기업개요 #1이며 #2~5까지 개선 완료했다는 뜻은 아닙니다.

- URL: https://g5themes.test/pages/company-overview-1.php
- 원본: themes/business/jw_business/src/php/pages/company-overview/1.php
- 스타일: themes/business/jw_business/src/styles/company-overview.css

## 연구에서 적용한 점

Enfold 비교 보고서의 '큰 이미지 다음 짧은 정보 구간', '메시지에 맞는 자료', '사진·기업표·과정 등 정보 형식 변화'를 적용했습니다.

1. 기존 분할 히어로 유지.
2. 기업명·사업 영역·협업 범위를 짧은 정보 띠로 추가.
3. 반복적인 철학 문장을 구체적인 역할 소개로 변경.
4. 사업 영역 3열 유지.
5. 사진 옆에 출발점·함께 할 일·확인할 자료를 제시하는 사례 예시 구성.
6. 네 단계와 각 단계의 공유 자료가 있는 협업 과정 구성.
7. 문의 CTA 유지.

기존 보유 사진을 사용했으며 Enfold의 이미지·소스를 복사하지 않았습니다. 새 사진 레퍼토리 확보는 미완료입니다. 사례는 가정임을 본문에 표시했고 매출·고객 수 등 가공 실적을 추가하지 않았습니다. 기존 사업 상세 링크 목적지는 아직 파사드가 있어 방문 경로 전체 완성으로 판정하지 않습니다.

## 함께 수정한 결함

모바일 게시판의 체크박스와 제목 사이에는 숨겨진 번호 td가 있습니다. 인접 선택자(+)로 제목 여백을 지정해 실제로 적용되지 않았습니다. 후속 형제 선택자(~)로 수정했습니다.

실제 관리자 공지 목록 390px에서 첫 3행 체크박스 오른쪽 35px, 본문 시작 44px, 간격 9px를 측정하고 화면에서 분리를 확인했습니다.

## 검증

- 테마 check: 26 tests / 135 assertions, 토큰·타입·빌드·산출물 검사 통과.
- 기존 Ubuntu PHP 8.3: 기업개요 #1 문법 검사 통과.
- 개발 사이트에 빌드 payload 반영.
- Edge PC 1440px 라이트에서 사례와 협업 과정까지 직접 스크롤 확인.
- 390px 모바일 다크 전체 페이지 시야 확인, 가로 넘침 없음.
- 공지 목록 390px 라이트에서 겹침 해소 직접 확인.
- 다른 4종과 전체 회원 기능, ZIP 설치 검증은 이번 완료 범위가 아님.

# Enfold 연구 적용 2차 — 기업개요 #2 자료형

## 반영

https://g5themes.test/pages/company-overview-2.php 에 실제 반영했습니다. 이번 범위는 #2이며 #3~5와 전체 테마 완료는 아닙니다.

기존 4단계 과정·반복 업무 공간 소개를 없애고, Enfold 연구의 정보 형식 변화와 자료 중심 탐색을 적용했습니다.

- 전폭 슬라이더: 외관·공동 검토·업무 환경으로 사진별 설명 역할 구분.
- 기업 정보표: 기존 구조 유지.
- 사업별 비교표: 과제, 검토 범위, 공유 자료를 함께 비교.
- 상담 준비: 목표/자료/일정의 세 항목을 아이콘 목록으로 구성.
- 상담 전 확인사항: native details로 개별 펼침.
- 문의: 기존 실제 문의 경로 연결. 존재하지 않는 다운로드를 만들지 않음.

#1의 사례·4단계 흐름을 복제하지 않았습니다. 보유 사진 재사용이며 새로운 사진 세트 확보는 아직 남았습니다. 제공 자료와 사업 내용은 시연 예시이며 실제 실적이 아닙니다.

## 검증

- 테마 check 통과: 26 tests / 135 assertions, 토큰·타입·빌드·산출물 검사.
- PHP 8.3 페이지 문법 검사 통과.
- Edge PC 1440px: 비교표와 자료 목록 직접 시야 확인.
- 슬라이더 다음 버튼: 1/3에서 2/3으로 이동하고 해당 사진 설명 변경 확인.
- 두 번째 상담 항목: 클릭 후 답변 펼침 확인.
- 처음 확인 중 자료 목록의 아이콘 등록 누락 발견 → Target/Files/Calendar 등록 후 실제 SVG 3개 확인.
- 모바일 390px 다크 전체 페이지 시야 확인. 문서 가로 넘침 없음.
- 모바일 표의 내부 viewport 333px / content 692px. 키보드 우측 이동 후 scrollLeft 증가 확인. 표 영역만 가로 스크롤.
- 자동 재생 시간 경과·스와이프·축소 동작 선호 조합 전수 검증은 이번에 수행하지 않음.

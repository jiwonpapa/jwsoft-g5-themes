# JW-Business 검색·새글 및 입력 정렬 개선

## 결과

2026-09-22 기존 개발 사이트 https://g5themes.test 에 빌드한 테마를 반영했습니다. G5 코어와 DB 스키마는 변경하지 않았습니다.

입력칸 48px, 버튼 44px를 별도로 지정했던 것이 4px 상단 어긋남의 원인이었습니다. `tokens/theme.tokens.json`에 control.height=48px를 정의하고 공통 입력·선택·버튼이 같은 CSS 변수를 사용하도록 수정했습니다. 모바일 검색행은 필터 아래 입력과 버튼을 같은 줄로 배치합니다.

## 구현 범위

- 전체검색: 검색 조건, 결과 게시판, 결과 목록, 페이지 이동을 새 마크업으로 교체. G5 검색 파라미터 유지.
- 새글: 그룹·원글/댓글·회원 검색, 목록, 선택 UI를 교체. 관리자 삭제 요청 형식 유지.
- 작성자 메뉴: 코어가 권한에 따라 제공한 링크를 native details 메뉴로 출력. 기존 인라인 스크립트 제거.
- 외부로그인·인기검색어: PC 스킨 교체 및 모바일 공용화. 위젯 별도 배치 화면과 소셜 로그인 연동 검증은 아직 남음.
- 기존 FAQ·1:1문의 등 공통 컨트롤에 동일 높이 적용.

## 실제 검증

| 화면 | 조건 | 결과 |
|---|---|---|
| FAQ | PC 라이트 | 수정 전 입력 48px/버튼 44px → 둘 다 48px, 상단 오차 0px |
| 전체검색 | PC 및 390px 모바일 | 입력·선택·버튼 48px, 같은 행 상단 오차 0px |
| 전체검색 | 서비스 검색 | 152건, 2개 게시판, 16페이지 결과 확인 |
| 새글 | 1440px PC 다크 및 390px 모바일 | 48px, 같은 행 상단 오차 0px, 모바일 가로 넘침 없음 |
| 새글 | 관리자 | 현재 페이지 15개 전체 선택/해제, 작성자 메뉴 펼침 확인. 삭제 실행하지 않음 |
| 1:1문의 | 1440px PC 및 390px 모바일 | 48px, 같은 행 상단 오차 0px, 모바일 가로 넘침 없음 |

전체검색 모바일, 새글 PC 다크·모바일 작성자 메뉴, 문의 모바일 화면을 직접 확인했습니다. 확인한 탭의 콘솔 오류는 없었습니다. 브라우저 크기와 라이트모드를 복원하고 검증용 탭을 닫았습니다.

- 테마 check: 토큰·타입·빌드·기존 테스트·산출물 검사 통과.
- 검색 유효성 테스트 추가 후 26개 테스트, 135개 assertion 통과.
- 서버 PHP 8.3에서 작성자 helper 문법 검사 통과. 검색·새글·외부로그인·인기검색어 PC 스킨 문법 검사도 통과.
- ZIP 재설치·전체 회원 단계·전체 기능 검증을 완료했다는 의미는 아닙니다.

## 남은 범위

설문, 본인인증, 모바일 최신글 캐러셀의 레거시 정리 및 외부로그인·인기검색어 별도 배치 시야 검증이 남았습니다. 기존 회원가입 주소행 등 모든 폼을 이번에 개별 검증한 것은 아닙니다.

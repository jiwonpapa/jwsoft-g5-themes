# JW-Business 기본 기능 점검·개선

대상: `themes/business/jw_business`, G5 5.6.391 개발 사이트 `https://g5themes.test/`.
범위: 갤러리, 로그인, 약관·회원정보 입력·가입 완료, 회원 비밀번호 확인, 게시판 글쓰기·본문·댓글. 코어·DB 스키마 변경 없음.

## 반영

- 갤러리의 구형 목록·본문·글쓰기·댓글 스킨을 교체했습니다. 목록은 이미지 그리드, 나머지는 기본 게시판의 동일 스킨을 재사용합니다. PC·모바일 모두 동일 source를 사용합니다.
- 분류, 선택 작업, 정렬, 검색, 페이지 이동을 유지했습니다. 비밀글 썸네일은 목록에서 출력하지 않습니다. 기존 fixture 이미지는 기능 검증용이며 상품용 사진 선정 완료를 뜻하지 않습니다.
- 가입 약관 → 정보 입력 → 완료에 공통 단계 표시를 추가했습니다. 완료 화면에는 계정 정보와 이메일 인증 설정에 맞는 안내만 출력합니다.
- 회원 비밀번호 확인, 게시물 비밀번호 확인, 계정 찾기·비밀번호 재설정 화면에서 구형 CSS·jQuery를 제거했습니다. 재설정 폼은 서버 처리 전에 성공했다고 표시하지 않습니다.
- 기존 로그인과 같은 폼·버튼·테마 색상을 사용합니다. 회원·글쓰기 컨테이너의 `border-box` 누락, 빈 추가정보 구역, 작은 안내문의 가독성, 모바일 페이지 번호 가로 넘침을 수정했습니다.
- 글·댓글·회원정보 제출은 비동기 검사 시작부터 잠그고 실패 시 해제합니다. 오류는 폼 내부의 알림 영역에 표시합니다.
- 댓글 수정·답변 취소로 원래 작성 위치와 상태를 복구합니다. 선택 복사·이동 후 목록 폼의 원래 action/target을 복원합니다.
- 본문 제목의 임의 잘림을 제거하고, 첨부파일 배열의 count 값을 이미지 처리에 넘기지 않습니다. 표·긴 코드·이미지 크기를 본문 폭 안에서 처리합니다.

| 현대화 자산 | 확인한 글쓰기·갤러리 화면에서 theme ESM 사용, jQuery/core common.js 로딩 없음 |

수동 Impeccable 감지에서 선택한 게시판·회원 source, 신규 community CSS, controller에 지적 없음. 자동 감지는 실제 화면 검증을 대체하지 않습니다.

## 남은 검증 경계

- 신규 회원의 실제 CAPTCHA 제출→계정 생성→완료 화면 도달은 미검증입니다. CAPTCHA를 우회하거나 설정을 해제하지 않았습니다. 완료 스킨의 출력 검사는 실제 신규 가입 성공과 구분합니다.
- 외부 본인확인·소셜 로그인·메일 발송은 미검증입니다. 설정된 제공자의 기존 URL 계약을 유지했으며 테스트를 위해 외부 전송하지 않았습니다.
- 이번 실제 저장 시험은 일반 텍스트 글·댓글 대상입니다. 외부 에디터, 실제 첨부 업로드, 비회원 비밀번호/삭제, 선택 복사·이동의 전체 서버 동작은 별도 회귀 대상입니다.
- 판매 ZIP 신규 설치·업데이트·롤백 시험은 이번 범위가 아닙니다.

## 반복 실행

- `php harness/g5-community/render-smoke.php`: DB·메일·세션 변경 없는 가입 완료 스킨 검사.
- `harness/g5-community/http-smoke.py`: 개발 호스트만 허용하는 opt-in HTTP 검사. 환경변수 `JW_G5_TEST_USER`, `JW_G5_TEST_PASSWORD`를 사용하며 비밀번호를 저장소에 넣지 않습니다. `--ca <mkcert CA 경로> --allow-test-writes`가 필요합니다.

수정 source는 `src/php`, `src/styles`, `src/scripts`입니다. 빌드 산출물만 기존 개발 사이트의 `theme/jw_business`에 반영했으며 `custom/`은 동기화에서 제외했습니다.

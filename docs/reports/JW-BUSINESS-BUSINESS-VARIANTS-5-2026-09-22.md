# 사업소개·사업상세 #5 구현 결과

## 반영

- 사업소개 #5: 방향·계획 / 정보·공간의 목적별 묶음. 사진과 분야별 설명, 관련 상세 링크 및 묶음 바로가기 구성.
- 사업상세 #5: 현황 정리 → 방향 합의 → 실행 계획 → 인계 확인. 각 단계의 확인 내용·산출물·다음 단계 조건을 설명.
- 실제 계약이나 실적으로 오인하지 않도록 협업 과정 예시임을 명시. 고정 기간·성과 수치 없음.
- 페이지별 제목·설명 메타 적용. native anchor와 기존 자산·토큰 사용, 신규 JS·라이브러리 없음.
- 수정 원본: `src/php/pages/page.php`, `business-route.php`, 신규 `business-list-5.php`, `business-detail-5.php`, `src/styles/company-overview.css`.
- Bun 생성 payload를 기존 g5themes.test에 반영. 코어·DB 변경 없음.

## 검증

- 테마 check: 26 tests / 135 assertions 통과. payload 420개.
- PHP 8.3: 라우터·공통 shell·신규 본문 2개 문법 검사 통과.
- Edge 1440×1000 PC 라이트 및 390×844 모바일 다크에서 두 페이지 전체 화면 직접 확인.
- 모바일 가로 넘침 없음. 상세 4개 단계와 2열 단계 메뉴, 단일 열 산출물 배치 확인.
- 실제 클릭: 소개 #5 → 과정·산출물 상세 #5 → 연락처 #1 컨설팅 안내 확인.
- 상세의 실행 계획 앵커 클릭 후 대상 top 110px 확인: 헤더에 가리지 않는 위치로 이동.
- 시험 후 viewport 해제·라이트 복원·임시 탭 정리.

## 현재 경계와 다음 작업

사업소개 5종과 사업상세 5종의 본문 구현을 마쳤다. 이전 차수별 시야 검증 기록은 각 보고서에 있다. 이번에 10개 페이지 전부를 다시 회귀 검사한 것은 아니다.

전체 테마·ZIP 설치 완료는 아니다. 문의 저장은 이번에 시험하지 않았다. 사진은 기존 자산 재사용으로 다양성이 제한된다.

다음은 **연락처 #2**부터 남은 연락처 변형을 구현한다. 연락처는 회사 설정을 재사용하고 별도 문의 저장 기능을 추가하지 않으며 기존 G5 1:1 문의로 연결한다. 그 밖의 일반페이지·잔여 기본 기능·판매 ZIP 검증은 별도 작업이다.

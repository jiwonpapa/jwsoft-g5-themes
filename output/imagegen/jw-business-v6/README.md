## 5차에서 유지·추가한 부분

5차의 밝고 조용한 건물 히어로, 오른쪽 사업 목록, 사진과 짧은 문구의 대표 사례, 텍스트 소식, 간결한 문의·푸터를 유지했다.

본문은 헤더·푸터를 제외하고 5개 구간에서 7개로 확장했다.

| 순서 | 구간 | 5차 대비 |
| --- | --- | --- |
| 1 | 히어로 | 유지 |
| 2 | 사업 소개 | 유지 |
| 3 | 기업 소개 | 추가. 협업 사진과 짧은 소개, 작은 실적 문구 |
| 4 | 대표 사례 | 유지 |
| 5 | 진행 과정 | 추가. 카드 배경 없는 3단계와 한 줄 설명 |
| 6 | 소식 | 유지 |
| 7 | 문의 안내 | 유지 |

사진은 2장에서 3장으로 늘렸다. 실적은 별도 큰 숫자 띠를 만들지 않고 기업 소개 안에 작은 문구로 넣었다. 18년·320건은 기존 가상 기업 시안의 예시 값이다. 큰 사진이 연속으로 쌓이지 않도록 사진 구간과 텍스트 구간을 구분했다.

## 육안 확인과 증거 범위

생성 결과에서 헤더·푸터, 7개 본문 구간, 사진 3장, 기업 소개 안의 작은 실적 문구, 카드 없는 진행 과정이 포함된 것을 직접 확인했다. 히어로의 빈 하늘 영역과 사업 소개 왼쪽의 빈 공간도 유지됐다.

이는 사용자 승인이나 실제 브라우저 검증을 뜻하지 않는다. 생성 이미지의 해상도·픽셀을 CSS 글자 크기나 정확한 DaisyUI 토큰의 증거로 사용하지 않는다. G5 기능·모바일·다크·접근성·모션은 이번 검토 범위가 아니다.

5차는 간결한 후보로 그대로 보존하고 6차와 비교한다. 기존 4차 반려안을 다시 채택하지 않으며 상품의 75개 페이지·섹션 라이브러리 범위를 변경하지 않는다.

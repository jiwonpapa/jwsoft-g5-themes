## 4차의 실패에 대한 변경

4차 최초안과 상·중·하단 수정안 모두 복잡한 화면 밀도와 여백 부족으로 반려됐다. 이미지 분할이나 상하 간격 증가만으로 해결했다고 판단하지 않는다.

5차는 메인에 모든 표현형을 전시하려는 구성을 줄였다. 사진은 히어로와 대표 사례 두 장만 사용한다. 사업 소개는 오른쪽 절반의 텍스트 목록에 두고 왼쪽 제목 아래 공간을 비운다. 대표 사례는 사진·짧은 제목·링크만 둔다. 소식은 텍스트 목록이며 문의와 푸터도 흰 바탕으로 이어진다.

히어로 사진은 복잡한 나무·건물 무늬 대신 밝은 하늘과 넓은 바닥을 가진 구도를 사용한다. 큰 실적 수치, 사업 사진 격자, 별도 과정 띠, 짙은 배경 구간을 이 메인 후보에서 제외했다. 이는 상품의 전체 페이지·섹션 제공 범위를 줄이는 결정이 아니다.

## 직접 확인한 범위

- 생성된 이미지 전체를 육안 확인했다. 헤더부터 푸터까지 포함되며 사진은 두 장이다.
- 사업 소개의 왼쪽 빈 공간, 사진 옆의 짧은 사례 설명, 낮은 밀도의 소식 목록이 실제 결과에 반영됐다.
- 모든 구간을 같은 크기의 굵은 제목과 사진으로 채우던 4차와 달리, 히어로 제목과 나머지 정보에 크기 차이가 있다.
- 이러한 관찰은 사용자 승인이나 객관적인 디자인 품질 인증을 뜻하지 않는다.
- 이미지는 가상 기업의 시안이다. 실제 CSS·DaisyUI 토큰·폰트·아이콘·모바일·다크·접근성·스크롤 효과·G5 기능을 검증한 산출물이 아니다.

현재 후보는 간결한 안으로 보존한다. 사용자의 추가 요청에 따른 [6차 비교 후보](../jw-business-v6/README.md)는 별도 파일이다. 기존 1~4차 파일은 비교 이력으로 유지하며 다시 승인된 기준처럼 사용하지 않는다.

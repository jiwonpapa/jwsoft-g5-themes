# JW-Business 1.0 — 4차 시안과 메인 수정본

- 작성일: 2026-09-21
- 방식: 내장 image_gen. 생성 원본을 복사하고 각 이미지의 정확한 프롬프트를 `*.prompt.txt`에 보존
- 현재 상태: **최초 메인과 상·중·하단 수정본 모두 반려. 기능 화면 4장은 보류**
- 실제 테마 소스 작성·서버 배포 없음

## 반려된 최초 4차

[최초 메인](01-home-light.png)은 사용자가 “전단지처럼 빽빽하다”, “3차와 무엇이 다르냐”, “여기저기 섞었느냐”고 지적했다.

원인은 여러 시안의 배치를 한 화면에 병합하면서 사진·제목·설명을 대부분의 구간에 채우고, 섹션마다 충분한 크기와 여백을 주지 않은 데 있다. 장점을 결합했다는 제작 의도를 품질 근거로 사용할 수 없다. 단순한 출력 이미지 축소 문제만으로 설명하지 않는다. 이 이미지는 구현 기준으로 채택하지 않는다.

지적 시점에 이미 요청되어 있던 기능 화면 생성은 중단 요청 전에 완료되어 반환됐다. 아래 네 장은 수정 메인과 다시 맞춘 결과가 아니며 채택·승인되지 않았다.

## 메인 수정본

아래 수정본도 사용자가 복잡하고 여백이 부족하다고 재차 지적했다. 최초안과 함께 채택 대상에서 제외하며 구현 기준으로 사용하지 않는다. 이후 후보는 [5차 메인](../jw-business-v5/README.md)에서 별도로 검토한다.

2차의 사진 중심 방향으로 돌아가, 한 번에 읽는 내용의 양과 사진 비중을 다시 정했다. 긴 페이지를 한 장에 압축하지 않고 이어지는 세 구간으로 생성했다. 이는 실제 브라우저 캡처나 픽셀 단위로 이어 붙인 완성 페이지가 아니라 배치와 화면 밀도를 검토하는 연속 이미지다.

1. [상단 — 히어로·사업 소개](01-home-upper-r1.png): 전폭 사진 히어로, 충분한 전환 여백, 큰 사업 사진 세 개. 최초 안의 작은 사진 모음과 별도 소개 문단 제거.
2. [중단 — 대표 사례·실적·과정](01-home-middle-r1.png): 대표 사례 하나를 크게 제시, 간결한 실적 수치, 짙은 바탕의 단계별 과정.
3. [하단 — 소식·문의·푸터](01-home-lower-r1.png): 사진 없는 소식 목록, 넓은 문의 안내, 정돈된 푸터.

상단은 `prototypes/business-theme-v2/previews/home-first-view.png`를 시각 참조로 사용했다. 중·하단은 수정 상단을 시각 참조로 사용했다. 최초 4차를 단순 확대하거나 여백만 늘린 편집본은 아니다.

## 확인 범위와 남은 사항

- 반환된 이미지에서 상단/중단/하단의 콘텐츠 구분과 끝 구간의 푸터를 육안 확인했다.
- 메인 수정본의 각 구간은 재검토 후 반려된 후보이며 사용자 승인으로 간주하지 않는다.
- 최초 기능 화면과 수정 메인의 로고 형태·색상·크기 등은 아직 통일되지 않았다. 기능 화면을 포함한 4차 완성 세트라고 보고하지 않는다.
- 생성 이미지의 픽셀은 정확한 DaisyUI 토큰·Pretendard·Lucide 구현 증거가 아니다. 실제 구현에는 정해진 semantic 색상과 자산이 필요하다.
- 기사 제목·날짜·댓글 수는 프롬프트에서 연결했다. 이미지 속 예시 데이터는 실제 G5 레코드가 아니다.
- PC 라이트 방향 검토만 해당한다. 모바일·다크·75개 페이지·스크롤 모션·G5 기능·권한·접근성·ZIP은 검증하지 않았다.
- 제품 범위는 기존 출시 계획을 유지한다. 대표 사례 하나를 보여 준다고 포트폴리오나 페이지 제공 수량이 줄어드는 것은 아니다.

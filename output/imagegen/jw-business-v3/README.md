## 참고 근거와 공통 표현

- [Avada Business](https://avada.website/business/)를 Edge에서 다시 열어 전체 페이지 화면을 직접 확인했다. 사진·밝고 어두운 면·소개·서비스·사람·뉴스를 구분하는 섹션 배치 원리를 참고했다. Avada의 사진·로고·문구를 시안 자산으로 복사하지 않았다.
- 기존 `prototypes/business-theme-v2/previews/01-home.png`를 직접 대조했다.
- 공통 헤더·푸터, 가칭 JW NEXUS, 한국어 본문, 파란 주요 버튼, 작은 모서리, 가는 선 아이콘을 같은 메인 참조로 유지했다.
- 프롬프트의 색상 기준은 기존 daisyUI corporate semantic 값이다. 생성 이미지의 픽셀이 정확한 토큰 값·Pretendard 폰트·Lucide SVG임을 보증하는 산출물은 아니다. 구현 시 실제 토큰·폰트·SVG로 고정해야 한다.

## 검토 범위

다섯 화면의 전체 구성, 동일 계열의 헤더·버튼·폼, 본문·댓글 3개·쓰기·가입의 주요 요소를 육안 확인했다. 회원가입 필수 표시를 글쓰기와 같은 오류색 계열로 한 차례 보정했다.

이미지의 날짜·조회수·업로드 용량·가입 조건과 권한별 버튼은 시안용 예시다. 실제 G5의 게시판·회원 설정 및 로그인 상태를 구현한 화면이 아니다. 목록·본문 사이 예시 날짜 등은 구현 fixture에서 통일해야 하며, 관리자 조작과 로그인 표시도 실제 권한에 따라 분리한다.

이번 산출물은 PC 라이트 5장이다. 모바일·다크·75개 페이지·모션·폼 제출·접근성·G5 권한·ZIP 동작을 검증한 결과로 사용하지 않는다. 웹 페이지/테마 소스는 작성하지 않았으며 서버에 배포하지 않았다.

Impeccable은 2차의 보조 `design.json` 갱신 차이를 알렸다. 이번에는 2차 원본과 보조 메타데이터를 변경하지 않고 별도 3차 PNG 후보를 생성했다.

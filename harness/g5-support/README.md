# FAQ·1:1 문의 검증

`g5themes.test` 전용입니다. 운영 사이트·코어·스키마를 수정하지 않습니다.

- `seed-faq.php`: CLI + `JW_G5_FIXTURE_ALLOWED=1`에서만 실행합니다. 기존 첫 FAQ 분류에 화면 예시 6개를 추가하며 동일 제목은 건너뜁니다. 기존 질문을 수정하지 않습니다.
- `http-smoke.py`: `JW_G5_TEST_PASSWORD` 환경변수와 `--ca <mkcert rootCA.pem> --allow-test-writes`가 필요합니다. 기본 계정은 admin이며 비밀번호를 파일에 기록하지 않습니다.
- 관리자 알림 이메일·휴대폰이 설정되어 있으면 시험을 중단합니다. 고객 이메일·SMS 수신도 선택하지 않습니다.
- 질문 생성/수정, 파일 두 개 첨부/다운로드/개별 삭제, 답변 생성/수정, 추가 질문/연관 질문, 검색, 모바일, 잘못된 토큰 거부를 검사합니다.
- 성공 시 G5의 토큰 기반 삭제 경로로 시험 질문·답변·첨부를 정리합니다. `--keep-fixtures`를 명시하면 보존합니다. 중간 실패 시 `JW_SUPPORT_<10자리 UUID>` 접두어의 해당 실행 데이터가 남을 수 있으므로 다른 자료와 구분해 정리합니다.
- 브라우저 JS 실행·모바일 배치·색상은 HTTP 검사와 별개로 직접 확인해야 합니다.

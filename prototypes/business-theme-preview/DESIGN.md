# JW FOLIO 승인용 디자인 기준

> 상태: 1차 이미지 시안, 미승인. 이 문서는 G5 테마 구현 사양이 아닙니다.

## 방향

`Corporate Specification Folio`를 작업 방향으로 삼습니다. 기업의 전문성을 큰 문구, 실제 공간과 사람 사진, 정돈된 사양표 같은 구분선으로 보여줍니다. 특정 제조 업종의 공장 이미지에 묶이지 않고 기술·건설·설계·전문 서비스·제품 기업에 모두 적용할 수 있어야 합니다.

화면에 표시하는 `JW FOLIO`는 승인용 가칭입니다. `Basic`은 공식 G5 원본을 가리키는 말로만 사용하며 상품명에 쓰지 않습니다.

## 공통 토큰

- 배경: Mineral Paper `#F2F3F5`
- 본문: Graphite `#111319`
- 강조: Cobalt `#2457FF`
- 보조 강조: Deep Cobalt `#1638A7`
- 선: Stone Line `#D5D7DC`
- 보조 문자: Muted Graphite `#686863`
- 흰 표면: `#FFFFFF`
- 본문 최대 폭: `1240px`
- 제목 서체: Pretendard 계열, 굵기와 자간으로 계층 구성
- 본문 서체: Pretendard 계열, 16px/1.7 기준
- 모서리: 입력창 2px, 작은 버튼 2px, 핵심 이미지 0px
- 아이콘: 24px 그리드, 1.8px 선, 둥근 선 끝

## 구성 원칙

- 모든 화면이 같은 헤더, 푸터, 버튼, 입력창, 아이콘 규칙을 공유합니다.
- 큰 사진은 메인과 게시물 본문에서만 핵심 증거로 사용합니다.
- 카드 묶음 대신 구분선, 번호, 여백과 정렬로 정보를 나눕니다.
- 기본 버튼은 코발트 단색, 보조 버튼은 투명 배경과 1px 테두리를 사용합니다.
- 게시판과 회원 화면은 G5 기능을 줄이지 않고 정보 위계를 정리합니다.
- 한국어 실제 길이의 제목·본문·도움말·댓글을 사용합니다.

## 승인 범위

1. 메인
2. 게시판 목록
3. 게시판 내용과 댓글
4. 글쓰기
5. 회원가입

다섯 화면의 시각 방향이 승인된 뒤에만 실제 G5 테마 파일을 만듭니다.

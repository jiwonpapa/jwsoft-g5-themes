2026-09-20 · 추가 시안 비교 전 · 실제 G5 상품 구현 아님

## 결과

`previews/01-home.png`, `02-list.png`, `03-view.png`, `04-write.png`, `05-register.png`가 PC 1440px 전체 화면입니다. 게시글은 댓글 3개를 포함합니다. 메인·목록의 다크 이미지와 다섯 화면의 모바일 이미지도 함께 제공합니다.

`review.html`은 생성된 PNG를 보는 검토용 갤러리입니다. `index.html?screen=home|list|view|write|register`는 PNG 렌더링용 정적 원본입니다. 데이터 저장·글쓰기·가입·에디터·슬라이드 동작을 구현한 제품이 아닙니다.

이 시안은 최종 방향으로 승인되지 않았습니다. 추가 시안 1종을 만든 뒤 형님이 비교해 선택하며, 그전에는 이 폴더의 레이아웃과 토큰을 실제 테마 기준으로 잠그지 않습니다.

## 새로운 구성

1. 전폭 사진 히어로와 슬라이드 진행 표시
2. 회사 소개서·사업·프로젝트 빠른 이동
3. 3분할 비대칭 사업 소개
4. 다크 배경의 실적 수치
5. 크기와 높이에 차이를 둔 프로젝트 슬라이드 구도
6. 네 가지 아이콘 역량
7. 현장 사진과 단계별 업무 과정
8. 사진 소식과 텍스트 소식의 혼합
9. 문의 CTA와 공통 푸터

이전 안의 큰 문장·가는 구분선 중심 구도에서 사진·정보 밀도·배경 전환이 있는 긴 기업 페이지로 변경했습니다. 섹션 조합 방향은 사용자의 설명을 반영한 것이며, 판매 종료된 과거 테마 화면을 이번에 직접 확인했다고 주장하지 않습니다.

## 색상·자산

- 라이트: daisyUI 5.7.42 `corporate`
- 다크: daisyUI 5.7.42 `business`
- 서체: Pretendard Variable 1.3.9, SIL OFL
- 아이콘: Lucide 1.47.0, ISC
- 공식 팔레트 소스: `vendor/corporate.css`, `vendor/business.css`
- 팔레트 안내: https://daisyui.com/docs/themes/
- 이미지 3종: Codex 이미지 생성. `assets/*.prompt.txt`에 정확한 프롬프트를 보존했고 PNG에도 삽입했습니다.
- 가칭 브랜드·기업·실적·주소·프로젝트·게시물·댓글은 시안용 가상 데이터입니다.

색상을 독립 HEX로 재정의하지 않았습니다. 약한 배경·구분선은 해당 daisyUI semantic color에서 혼합합니다. 어두운 배경의 작은 아이콘·분류 글자는 같은 팔레트의 secondary를 사용합니다.

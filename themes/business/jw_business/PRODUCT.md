# JW-Business 1.0 상품 계약

- 상태: 기반 재설계 중. 공식 basic 반입과 build 골격은 유지하되, 기존 공통 화면·메인 source는 레거시 CSS·DOM·JavaScript 결합으로 상품 기준선에서 제외. 공개 route 계약표와 문서 shell부터 재구축할 단계.
- 대상: 기업·전문 서비스 사이트를 제작하는 구매자와 기업 정보·사업·자료·연락처를 찾는 방문자.
- 설치 경로: `theme/jw_business`. 다른 테마를 부모로 요구하지 않는 독립 테마.
- 기준: G5 `v5.6.391`, commit `148d748c2d3fe60a536966164d1d7dbbe6f9c477`.
- 기준 환경: PHP 8.3 / MySQL 8.4. PHP 8.4·8.5 / MariaDB 10.11은 검증할 호환 대상이며 현재 통과 선언이 아닙니다.

## 확정된 출시 범위

루트 [출시 구현 범위](../../../docs/plans/JW-BUSINESS-1.0-IMPLEMENTATION-SCOPE.md)를 단일 기준으로 사용합니다.

- 메인 5종 + 일반 페이지 14유형 × 5종 = 75개 레이아웃.
- 게시판 6개·최신글 8개 표현형, G5 커뮤니티 기본 기능·PC/모바일 전체.
- 공개 화면 전체 라이트·다크, 복사 가능한 섹션, 페이지별 meta·실제 게시글 기반 구조화 데이터 출력.
- 온라인 매뉴얼, 독립 설치 ZIP, 별도 개발 키트 ZIP, 설치·수정·업데이트·복구 안내, 구매자용 AI 헌법과 개발 하네스.
- 영카트·빌더·별도 에디터·업로더·예약·외부 API 연동 제외.

## 디자인 진행

2026-09-21 실제 화면 검토에서 기존 구현을 반려했습니다. 6차 메인은 정보 구조 참고로만 유지하며 구현 기준선이 아닙니다.
새 디자인은 [레거시 제거·현대화 실행 계획](../../../docs/plans/JW-BUSINESS-LEGACY-MODERNIZATION-PLAN.md)의 공통 기반 gate를 통과한 뒤 다시 구현합니다.

색은 daisyUI를 원본으로 한 `jw-light`·`jw-dark` 사용자 정의 theme로 고정합니다. 색상뿐 아니라 글자·간격·container·모서리·그림자·동작 token을 먼저 확정합니다.

## 판매·지원

- 기존 판매중단 상품 기록 교체. 정가 39만 원, 출시 한 달 실제 판매가 29만 원, 쿠폰 미사용.
- 회사·개인 귀속 무제한 사용, 재판매 금지, 다운로드한 버전 지속 사용, 업데이트·기본 지원 1년 방향.
- 기본 지원: 테마 자체·명시 환경 호환·보안 오류, 문서대로 재현되는 설치 오류. 변경 위치·활용법은 매뉴얼로 안내.
- 기존 구매자 권한·판매처 조건·최종 라이선스 문구는 출시 전 확인 사항입니다. 이 문서는 최종 라이선스가 아닙니다.

## 현재 단계

- 완료: 460개 반입, 표시 이름·파일 hash·분류 기록, Bun/Vite·Tailwind/DaisyUI build, 로컬 Pretendard·선택 Lucide, 구매자 개발 키트의 setup·doctor·AI 계약, 공개 레거시 감사와 현대화 순서 확정.
- 다음: 공개 route·의존성 계약표 → `head.sub.php`/자산 그래프 → token/공통 DOM → 네이티브 메뉴 → G5 adapter.
- 확인: Ubuntu PHP 8.3 환경에 개발 payload 388개 적용과 Edge 렌더링으로 구조 결함을 확인. 200 응답은 상품 품질이나 구현 완료 증거로 사용하지 않음.
- 미실행: 모바일·라이트/다크·회원 상태·기능 화면 전체 검증, 판매 ZIP 설치·업데이트·원복.

반입한 기존 스타일·이미지·jQuery·Font Awesome·예제 게시판 ID는 최종 설계 채택이나 자산 배포 승인으로 간주하지 않습니다.

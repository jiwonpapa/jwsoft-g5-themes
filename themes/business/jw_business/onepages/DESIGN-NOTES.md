# 독립 원페이지 3종 — 최종 디자인 기록

2026-09-22. 기존 JW-Business 시각 체계 안에서 만든 별도 작성본입니다. 이 문서는 세 원페이지의 구현을 설명하며 전역 디자인·상품 계약을 새로 정의하지 않습니다.

이후 사용자 지시로 개발 사이트에 배포하고 메인 메뉴에 연결했습니다. 현재 상품 경로와 검증 범위는 [7종 개선 보고서](../../../../docs/reports/JW-BUSINESS-MAIN-SEVEN-IMPROVEMENT-2026-09-26.md)를 따릅니다.

첫 화면은 각각 제품의 형태, 상담 장면, 공간의 크기를 중심에 둡니다. 세 페이지 모두 시연·가상 자료임을 실제 본문에 밝히며 문의는 기존 G5 `/bbs/qalist.php`로 연결합니다.

## 상속한 시각 체계

- 색상은 `src/styles/theme.css`의 `jw-light`·`jw-dark`에서 `--color-base-100`, `--color-base-200`, `--color-base-content`, `--color-primary`를 상속합니다. 원페이지의 배경·보조 면·본문·포커스가 이 값에 연결되며, 본문 버튼은 잉크색과 배경색의 대비를 사용합니다.
- 글꼴은 기존 `Pretendard Variable`입니다. 원페이지 기본 제목은 굵기 700, h1 `clamp(2.7rem, 5.6vw, 5rem)`, h2 `clamp(2rem, 3.6vw, 3.5rem)`, h3 `1.4rem`이며 첫 화면별 조정이 있습니다. 본문 행간은 1.75, 도입 문장은 `1.15–1.5rem`, 보조 설명은 주로 `0.875rem`입니다.
- 본문 폭은 최대 1200px, 기본 좌우 여백은 48px입니다. 960px 이하에서 24px로 줄고, 767px 이하에서 주요 2열 구성이 1열이 됩니다. 섹션 간격은 72–140px이며 모바일에서는 72px를 사용합니다.
- 일반 영역은 색 면과 가는 구분선으로 나눕니다. 버튼은 8px 모서리와 최소 48px 높이를 사용합니다. 이는 이 묶음의 구현값이며 전역 토큰을 변경하지 않습니다.
- 제품 이미지·회전 영역의 차콜 배경은 해당 제품 장면에 한정합니다. 첫 화면의 짧은 제목 진입과 프로젝트 이미지 움직임은 동작 줄이기 설정에서 제거됩니다.

## 자산 출처와 일관성

- `node-poster.webp`, 상세 탭 이미지, `node-001.webp`부터 `node-036.webp`까지 모두 `design/node-concept.blend`의 같은 가상 제품 모델을 사용합니다. 대표 이미지는 `render-node-poster.py`, 모델과 회전 장면은 `render-node.py`, WebP 변환은 `prepare-assets.mjs`로 재생성할 수 있습니다. 회전 묶음은 960×640이며 36장 합계 약 552KiB입니다.
- `courtyard.webp`와 같은 공간을 다르게 보여주는 다섯 장은 내장 imagegen으로 만든 가상 프로젝트 이미지입니다. 서비스 첫 화면의 `service-workshop.webp`도 전용 이미지입니다. 이전의 테마 사진 복사본 두 장은 이번 개선에서 제거했습니다. 신규 프롬프트는 `design/IMAGE-PROMPTS.md`를 따릅니다.
- 초기 생성 제품 이미지 `design/node-study.webp`는 참고 보관본이며 공개 페이지에서 사용하지 않습니다. 공간 갤러리도 동일 실재 건축물의 기록이 아닙니다. 실상품 적용 시 실제 제품·프로젝트 자료와 검증된 설명으로 교체합니다.
- 제품 탐색 화살표는 인라인 SVG입니다. Blender는 제작 도구이며 고객 브라우저는 사전 렌더링된 WebP만 사용합니다.

## 확장 경계

각 PHP가 전체 본문을 직접 소유하고 기존 `common.php`, 테마 `head.php`·`tail.php`를 사용합니다. CSS는 `.jwo` 아래에 제한하며 JS 동작은 해당 원페이지를 기준으로 조회합니다. 파일 전달 위치와 연결 방법은 [README.md](README.md)를 따릅니다.

세 원페이지는 메인 메뉴와 G5 공통 shell에 연결되고, PHP·빌드된 CSS/JS·이미지는 테마 payload에 포함됩니다. 고객 서버에 Blender·Node·Bun 실행을 요구하지 않습니다. `design/`, 문서, 개발 harness와 검토 캡처는 웹 공개용 자산이 아닙니다. 판매 ZIP은 전체 품질 차단을 통과하기 전까지 발행하지 않습니다.

## 확인한 증거와 한계

문서화 기준은 PHP 3종, `assets/onepages.css`·`onepages.js`, 기존 테마 색상·글꼴 정의, `PRODUCT.md`, README, 제작 기록과 렌더 스크립트, 해당 surface brief입니다. 저장된 PC·모바일 화면은 저장소 `.impeccable/review/onepages/`에 있습니다.

작업에서 기록한 검증 범위는 로컬 fixture의 PC 1440×1000 / 모바일 390×844, 대표 동작, 동작 줄이기, 서비스형 다크 화면, 가로 넘침, 프레임 실패 및 JS 비활성 대체 표현입니다. 독립 최종 검토의 `ship`은 동일 모델 일관성과 SVG 화살표의 두 수정 항목을 해결한 판정이며, 실제 G5 통합 승인을 의미하지 않습니다.

후속 작업에서 실제 G5 메뉴·PC/모바일 공통 shell 및 Ubuntu 배포를 확인했습니다. 로그인·게시판 권한, 영카트, 판매 ZIP 설치·업데이트·롤백과 전체 품질 승인은 이 기록의 증거 범위 밖입니다. 저장된 캡처만으로 해당 검증을 통과했다고 간주하지 않습니다.

## 기존 문서 차이

기존 `PRODUCT.md`에는 공통 기반 재설계 대기 상태가 남아 있고 `docs/START-HERE.md`에는 이후 구현 기록이 있습니다. 이번에는 그 전역 진행 상태를 정정하지 않았습니다. 기존 코드의 색상·글꼴을 상속했으며 `DESIGN.md`·`.impeccable/design.json`의 부재를 새 디자인 체계 생성 권한으로 해석하지 않았습니다. 전역 설정과 관련 없는 동시 변경도 보존했습니다.

# JW-Business 1.0 Developer Kit

이 디렉터리의 파일은 최종 개발 키트 ZIP 루트에 배치할 구매자용 안내 원본입니다.

- `AGENTS.md`: AI와 사람이 따라야 할 수정 헌법
- `DEVELOPMENT-CONTRACT.json`: 도구 버전, 명령, 수정·생성·금지 경계를 담은 기계 판독 계약
- 상세 절차: `themes/business/jw_business/docs/manual/LOCAL-DEVELOPMENT.md`

개발 키트는 테마 빌드만 제공하며 웹서버·PHP·DB·그누보드5 실행 환경을 만들지 않습니다.

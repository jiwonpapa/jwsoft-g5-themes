# 변경 기록

## 1.0.0-dev.1 — 2026-09-21

- 공식 G5 5.6.391 basic 460개 전체 반입, 표시 이름을 JW-Business 1.0으로 변경.
- 파일 목록·checksum·상품 제외 범위, 테마별 작업 지침과 상품 계약 기록.
- DaisyUI 의미 색상 변수에 연결하는 토큰 골격 생성. 화면 적용 전.
- Bun/Vite, Tailwind CSS, daisyUI, Pretendard, Lucide를 exact pin하고 오프라인 payload build를 구현.
- `corporate`/`business` 초기 선택·저장·전환과 스크롤 방향 반응형 헤더 controller 골격 추가.
- 공통 헤더·G5 메뉴·모바일 dialog 메뉴·로그인 상태·검색·1:1문의·푸터를 PC/모바일 공용 partial로 구현.
- 히어로, 서비스, 회사·실적, 프로젝트, 진행 과정, G5 최신글, 문의의 메인 7개 섹션 구현.
- 메인용 생성 이미지 3개를 WebP로 최적화하고 프롬프트·출처·checksum·라이선스 식별자를 기록.
- `custom/site.php` 선택 설정으로 브랜드·메인 문구·사업·소식 게시판·회사 정보를 코어 수정 없이 바꿀 수 있도록 구성.
- 영카트 174개와 기존 basic 미리보기 이미지를 판매 payload에서 제외하고 커뮤니티 파일 누락을 검사.
- 개발 시작 기록이며 상품 출시·실행 검증·배포 완료를 뜻하지 않음.

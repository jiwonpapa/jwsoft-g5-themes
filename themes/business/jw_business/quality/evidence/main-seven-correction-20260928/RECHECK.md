7종 교정 빌드에서 `bun run ui:check` 56상태 통과, 실제 동작 수집 40건 통과, 제품 회전 10조건 통과, 테마 테스트 65건 통과했습니다. 이후 쇼케이스의 사용 경험·설치 안내·FAQ 배경을 회색·흰색·회색으로 다시 구분해 사무실에 반영했고, 해당 페이지 8상태를 재검사해 모두 통과했습니다. 신규 이미지 3개의 사무실 배포본 SHA-256은 로컬 payload와 일치했습니다. `PHOTO_REPEAT_WITHIN_PAGE`는 같은 페이지 PHP 마크업의 동일 이미지 경로 반복을 차단하며, 서로 다른 크롭이나 CSS 배경의 시각적 유사성은 직접 검토해야 합니다.

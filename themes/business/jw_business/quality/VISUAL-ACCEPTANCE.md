# JW-Business 메인 7종 시각 합격 기준

2026-09-28 제정한 **검수 기준**입니다. 대상은 메인 1–4와 제품·서비스·프로젝트 원페이지 3종입니다. 이 문서는 현재 페이지의 합격 선언이 아닙니다. `contract.json`, `assets.json`, `quality:check`·`quality:complete`의 기존 차단을 완화하지 않습니다.

## 목표와 비교 범위

형님이 말씀하신 “Enfold·Avada의 50% 수준”은 품질을 숫자로 반토막 내겠다는 뜻으로 해석하지 않습니다. 두 상품의 빌더·요소 수·데모 수를 복제하지 않고, **방문자에게 보이는 완성된 페이지의 최소 설득력**을 목표로 삼습니다. 비교 기준은 [Enfold 완성 데모](https://kriesi.at/themes/enfold-2017/), [Enfold 요소 예시](https://kriesi.at/themes/enfold-2017/elements/), [Avada 완성 사이트 목록](https://avada.com/prebuilt-websites/)입니다. 참고 대상은 정보 전개, 자료의 역할, 섹션 리듬과 마감입니다. 상대 테마의 이미지·문구·소스를 복사하지 않습니다.

이 제품의 합격선은 “첫 화면에서 역할이 보이고, 스크롤할 때 실제로 다른 종류의 자료를 발견하며, 마지막에 선택 또는 문의할 이유가 남는 7개의 서로 다른 시연 페이지”입니다. 섹션 개수, 페이지 길이, 애니메이션 횟수만으로 점수를 주지 않습니다. 그누보드 기능·ZIP 설치와 판매 승인도 별도 판정입니다.

## 구현 전 고정할 입력

각 페이지를 고칠 때 다음 다섯 가지를 **PHP/CSS 수정 전** 한 장의 디자인 카드에 고정합니다. 현재 `DESIGN.md`의 Pretendard, DTCG, `jw-light`·`jw-dark`, Lucide, Motion, Embla와 페이지 파일 소유권을 유지합니다.

1. **한 문장 목적과 다른 6종과의 선택 이유:** 방문자가 무엇을 보고 판단하는 페이지인지 적습니다.
2. **PC·모바일 전체 스토리보드:** 첫 화면, 중간 핵심 장면, 끝 행동을 썸네일로 나열합니다. 각 섹션의 정보 역할과 레이아웃 유형을 표시합니다. 텍스트·빈 색면만 있는 초안은 시각 승인에 쓰지 않습니다.
3. **실제 자산표:** 각 장면에 들어갈 페이지 소유 사진·렌더·큰 아이콘·도해·목업의 원본과 권리를 기록합니다. 크롭과 파일명 변경을 새 자료로 세지 않습니다. 자료가 없으면 그 장면은 미완료입니다.
4. **타이포·정렬·색의 기준 화면:** 1440×1000과 390×844의 라이트·다크에서 제목, 본문, 이미지, CTA의 관계가 읽히는 시안을 준비합니다. 1920px의 과도한 빈 공간과 768px의 열 충돌도 예상합니다.
5. **동작의 이유:** 슬라이더·회전·스크롤 연출이 무엇을 새로 보여주는지, 정지·키보드·reduced motion에서 어떻게 읽히는지 씁니다. 강한 강조는 의미 있는 한두 장면에만 배치합니다.

7종의 고유 역할은 다음처럼 유지합니다. 같은 영웅 사진·제목·카드 배열을 문구만 바꿔 복제하지 않습니다.

| 페이지 | 첫 화면과 중간에 보여야 할 고유 자료 |
| --- | --- |
| 메인 1 | 기업 서비스의 폭을 보여주는 슬라이드와 업종·전략·사례·브랜드의 서로 다른 매체 |
| 메인 2 | 선택 우선순위를 설명하는 첫 화면과 실제처럼 읽히는 판단 지도·비교 자료 |
| 메인 3 | 결과물을 먼저 보는 포트폴리오 첫 화면과 사인·인쇄·전시·디지털의 매체 차이 |
| 메인 4 | 한 브랜드 사례의 강한 첫 장면과 발견→제작→인계의 실물·화면 결과물 |
| 제품 원페이지 | 한 제품의 설득력 있는 정지 컷·재질 접사·사용 장면·스크롤 회전 |
| 서비스 원페이지 | 제공 범위를 구분하는 큰 의미 아이콘, 과정 자료, 화면·인계물 시안 |
| 프로젝트 원페이지 | 공간 장면, 평면·동선, 재료, 크기가 충분한 갤러리 |

## 화면 판정표

각 축은 0·1·2점입니다. **0은 결핍, 1은 읽히지만 평범하거나 일관성이 약함, 2는 페이지 목적에 맞게 설계되고 네 상태에서 확인됨**을 뜻합니다. 구체적인 반례와 해당 원본 캡처 위치를 기록하지 않은 점수는 무효입니다. 숫자는 심사 대화의 압축 표기이지 취향을 기계적으로 객관화한 값이 아닙니다.

| 축 | 0점 | 1점 | 2점 |
| --- | --- | --- | --- |
| 첫 화면·정체성 | 문구를 가리면 다른 페이지와 구분되지 않거나 큰 글자만 지배 | 목적은 알 수 있으나 기억할 시각 장면이 약함 | 3초 내 페이지 역할과 주인공 자료가 보이고 CTA가 장면에 붙어 있음 |
| 사진·아이콘·자료 | 반복 사진, 텍스트 상자 대용 자료, 목적과 맞지 않는 렌더 | 관련 자료가 있으나 종류·디테일·배치가 부족 | 고유 자산이 서로 다른 질문에 답하고 사진·아이콘·도해·실물/화면 시안이 역할에 맞음 |
| 서사·섹션 리듬 | 인접 섹션이 큰 제목+짧은 문장/동일 카드의 반복, 길이만 늘어남 | 중간 변화가 있으나 흐름·정보 밀도가 단조로움 | 도입→근거/경험→결정의 흐름에서 크기·배경·구도·매체가 이유 있게 바뀜 |
| 타이포·정렬·테마 | 잘림·겹침·뒤집힌 글자·CTA 오정렬·다크 붕괴 | 모두 읽히지만 넓은 화면의 쏠림 또는 제목/사진 관계가 거침 | 큰 제목과 이미지가 균형 잡히고 기준선·줄바꿈·간격·두 테마가 PC·모바일에서 안정적 |
| 동작·조작 | 장식만 흔들리거나, 슬라이드/갤러리가 거의 변하지 않거나, 필수 정보가 동작에 가림 | 의미 있는 변화 1곳이 있으나 강조·제어가 약함 | 페이지의 핵심 자료를 드러내는 주목 장면 1–2곳과 절제된 보조 동작; 키보드·정지·reduced motion도 읽힘 |

**페이지 시각 합격:** 총 8/10 이상, 첫 화면·자산·타이포는 각각 2점, 나머지는 각각 최소 1점, 아래 즉시 불합격 0건. 7종 묶음 합격은 개별 합격에 더해 기존 `quality/README.md`의 메인 6쌍·원페이지 3쌍 비교에서 첫 화면과 중간 두 장면을 **문구를 가린 상태로도** 서로 구분할 수 있어야 합니다. 쌍별 이유를 자산·구도·정보 역할로 적습니다. 점수만 높여 묶음 차별화 실패를 덮지 않습니다.

**즉시 불합격:** 잘린·겹친·뒤집힌 글자, 클릭부와 이미지의 접촉, 한쪽으로 무너진 정렬, 모바일/다크에서 사라진 자료·CTA, 과장된 가상 성과나 없는 기능의 암시, 다른 페이지의 원본 사진 재사용, 작동이 보이지 않는 슬라이더/회전, 같은 큰 제목+문장 또는 같은 카드 구도가 세 섹션 연속, 원페이지인데 목적·근거·결정/문의 중 하나가 빠진 경우입니다. 섹션 경계가 배경·밀도·자료·여백 중 어느 것으로도 보이지 않는 인접 두 구간도 재설계 대상으로 표시합니다. 오류가 한 상태에서만 나와도 전체 페이지는 보류합니다.

## 증거와 중단 규칙

- 수정 전 현재 `g5themes.test`와 해당 소스 hash를 고정합니다. 구현 전 디자인 카드와 기존 화면을 대조해 **바꿀 구간·유지할 구간·자산**을 결정합니다. 카드와 실제 자료를 확인하지 않은 채 CSS 수치만 바꿔 시각 결함을 봉합하지 않습니다.
- 구현은 페이지 목적과 매체 구성을 바꾸는 **한 묶음**으로 합니다. 제작자는 실제 G5에서 1440×1000·390×844의 라이트/다크 전체 화면과 상단·중간·끝 원본 크기를 봅니다. 1920·768px은 해당 레이아웃 위험 구간을 확인합니다. 슬라이더·회전·갤러리는 전후 상태를 조작해 남깁니다.
- 독립 검토자는 위 판정표의 5점수와 즉시 불합격, 9쌍 차별성을 원본 캡처에 연결합니다. 자동 감지, DOM 개수, 스크린샷 파일 존재, 기존 수정 항목의 `pass`는 시각 합격을 대신하지 않습니다. 입력이 바뀌면 관련 캡처와 검토를 다시 만듭니다.
- **한 페이지는 설계안 1회 → 구현 1회 → 묶음 수정 1회 → 최종 재검수 1회**로 마칩니다. 최종에도 불합격이면 작은 땜질을 반복하지 않고 페이지 설계 카드/자산 선택으로 되돌려 새 방향을 결정합니다. 재설계 대상은 판매 합격으로 포장하거나 다른 페이지 개선의 기준으로 복제하지 않습니다.
- 이 시각 합격 이후에도 `bun run quality:complete home`, `bun run quality:complete onepage`, 전체 상품 `quality:release`, G5 회원·게시판, ZIP 설치·업데이트·롤백은 각각 별도 통과가 필요합니다.

## 현재 증거의 판정 범위

[메인 7종 독립 검토](../../../../docs/MAIN-SEVEN-INDEPENDENT-REVIEW-2026-09-28.md)는 목적·이미지·구성과 특정 F1–F3 수정에 `pass`를 남겼습니다. [후속 교정 검토](../docs/MAIN-SEVEN-CORRECTION-INDEPENDENT-REVIEW-2026-09-28.md)는 제품 목재 질감 교정과 제한된 회귀를 확인했습니다. 이는 이 문서의 **5축 점수와 즉시 불합격 전체를 소급 승인한 기록이 아닙니다.** 2026-09-28 실행한 `bun run quality:check`도 현재 작성 23페이지 범위에서 실패했습니다. 따라서 **현재 7종의 판매 시각 합격은 미판정·보류**로 둡니다. 이후 7종을 동일 판정표로 한 번에 재평가하고, 실패 축이 확인된 페이지에만 새 디자인 카드를 작성합니다.

다음 실행은 화면 7개를 동시에 고치는 일이 아닙니다. 먼저 같은 날짜·같은 빌드의 7종 28상태를 위 표로 채점하고 9쌍을 비교합니다. 그다음 즉시 불합격이 있는 페이지, 필수 2점 축이 가장 약한 페이지 순으로 디자인 카드를 작성합니다. 수정 후 동일한 장면을 비교하며 합격·불합격을 기록합니다. 이 순서를 건너뛰고 “개선 완료”를 선언하지 않습니다.

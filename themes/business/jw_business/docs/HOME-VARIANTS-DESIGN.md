# JW-Business 메인 2~5 디자인 기록

2026-09-22. 대상은 `src/php/index_2.php`~`index_5.php`와 `src/styles/home-variants.css`입니다. 기존 디자인 체계의 확장을 기록하며 전역 `DESIGN.md`나 별도 token 원본을 만들지 않습니다. 실제 화면의 합격 여부·검사 결과는 메뉴별 검증 보고서에서 관리합니다.

## Overview

기존 JW 공용 헤더·푸터, Pretendard, `jw-light`·`jw-dark`를 유지합니다. 네 메인은 제목이나 카드 수만 바꾸지 않고 방문자가 읽는 순서를 달리합니다.

| 선택 파일 | 첫 화면 | 이어지는 읽기 순서 |
| --- | --- | --- |
| `index_2.php` | 사업 설명과 협업 사진 | 사업 바로가기 → 분야별 설명 → 공간 시연 사례 → 회사소개 → 문의 |
| `index_3.php` | 프로젝트 소개와 대표 사례 사진 | 대표 사례 → 크기·위치가 다른 사례 두 개 → 결과를 설명하는 질문 → 상담 |
| `index_4.php` | 세 단계와 각 단계의 산출물 | 상세 과정 → 협업 장면 → 질문 펼침 → 문의 |
| `index_5.php` | 기업 공간 사진과 소개 | 내부 목차 → 회사소개 → 사업 → 시연 사례 → 설정값 기반 연락처 |

본문은 각 PHP에 모두 들어 있습니다. 기본 초기화와 공용 head·tail을 사용하며 본문 partial이나 화면 dispatcher는 두지 않습니다. 홈 선택은 [홈 교체 매뉴얼](manual/HOME-SELECTION.md)을 따릅니다.

## Colors

색상 원본은 [DTCG token](../tokens/theme.tokens.json), `jw-light`·`jw-dark`의 실제 값은 [공용 스타일](../src/styles/theme.css)입니다. 메인 전용 스타일은 바탕에 `--color-base-100`·`--color-base-200`, 본문에 `--color-base-content`, 주 행동에 기존 primary control을 사용합니다. 링크·단계 번호·초점에는 [공용 커뮤니티 스타일](../src/styles/community.css)의 `--jw-link-ink`를 재사용합니다.

메인 전용 구분선은 본문색 20%와 투명의 `color-mix(in oklab, …)` 조합입니다. 5번 사진 위 흰색 글자와 어두운 오버레이는 해당 사진면의 가독성 처리이며 새 브랜드 색상으로 등록하지 않습니다.

**기존 의미색 유지 규칙.** 메인 변형을 수정할 때 기존 의미색과 라이트·다크 대응을 유지하고 새 팔레트를 별도로 선언하지 않습니다.

## Typography

폰트는 공용 스타일의 `Pretendard Variable`을 상속합니다. 아래 값은 메인 2~5 범위에 실제 선언된 크기이며 전역 typography token으로 승격한 값이 아닙니다.

| 역할 | 크기 | 두께·행간 |
| --- | --- | --- |
| 주요 제목 | `clamp(38px, 4.6vw, 66px)` | 740 / 1.25 |
| 섹션 제목 | `clamp(29px, 3.1vw, 43px)` | 700 / 1.25 |
| 하위 제목 | `clamp(23px, 2.2vw, 30px)` | 680 / 1.25 |
| 본문 | PC 17px, 모바일 16px | 상속 / 1.8 |
| 도입문 | `clamp(19px, 1.65vw, 23px)` | 상속 / 1.75 |
| 이미지 설명·시연 안내 | 14px | 상속 / 1.65 |

제목은 `word-break: keep-all`, 균형 줄바꿈, 자간 `-.035em`을 사용합니다. 본문은 한국어 단어 흐름을 유지하면서 긴 문자열에는 줄바꿈을 허용합니다. 3번 사례 제목, 4번 단계명, 5번 사진 위 도입문에는 해당 구성에 맞춘 별도 크기가 있습니다.

## Layout

본문 최대 폭은 기존 홈과 같은 1280px입니다. 메인 변형의 좌우 여백은 넓은 화면 40px, 1100px 이하 24px, 767px 이하 20px입니다. 일반 섹션 세로 여백은 `clamp(64px, 7vw, 104px)`이며 첫 화면·사례 목록·문의 띠는 별도 간격을 사용합니다.

767px 이하에서 주요 두 열 구성은 한 열로 전환합니다. 3번 사례의 엇갈린 세로 배치는 해제하고, 4번 과정 설명의 sticky는 일반 흐름으로 바뀝니다. 5번 내부 목차는 공용 헤더 아래에 붙도록 PC 76px·모바일 68px 위치를 사용합니다. 해당 치수는 공용 헤더가 바뀌면 함께 확인해야 합니다. 내부 이동 대상의 위쪽 여유는 160px입니다.

**읽기 순서 유지 규칙.** 모바일에서도 본문 순서를 유지하며 사진·과정·설명·다음 행동이 사라지지 않도록 구성합니다.

## Elevation & Depth

새 메인 본문은 평면 배경, 사진 크기, 얇은 구분선으로 내용을 나눕니다. 메인 전용 그림자는 추가하지 않았습니다. 공용 헤더의 스크롤 상태 그림자는 기존 구현을 사용합니다.

## Shapes

사진과 본문 구획은 직선 형태입니다. CTA는 기존 `jw-control`의 모서리와 `--jw-control-height`를 사용합니다. 단일 행 control 높이 48px는 DTCG token 원본에 있으며 메인별로 새 높이를 정하지 않습니다. 일반 텍스트 링크는 충분한 클릭 영역을 별도로 둡니다.

## Components

- 사업 바로가기와 분야 목록: 2번에서 목차와 상세 탐색을 연결합니다. 모바일은 세로 목록으로 표시합니다.
- 사례 링크: 3번에서 사진·제목을 하나의 링크로 묶고 hover 시 제목 밑줄을 표시합니다. 시연 사례임을 본문에 명시합니다.
- 과정·산출물: 4번에서 목록과 정의 목록을 사용합니다. 질문은 네이티브 `details`·`summary`이며 첫 질문이 기본 펼침입니다.
- 내부 목차: 5번에서 실제 section ID에 연결합니다. 연락처는 회사 설정값을 출력하며 온라인 문의는 G5 문의 경로로 연결합니다.
- 문의 띠: 2·4번의 [복사용 블록](../blocks/home/contact-band-01.php)을 각 PHP에 직접 복사하고 출처 주석을 남깁니다. 실행 시 블록을 include하지 않습니다.

키보드 초점은 링크·summary에 3px outline과 5px 여유를 둡니다. 입장 이동, 사진 밝기 hover, 화살표 이동은 `prefers-reduced-motion: no-preference`에서만 적용합니다. 입장 효과는 위치만 바꾸며 기본 콘텐츠를 숨기지 않습니다.

사진은 기존 `home-hero.webp`, `home-collaboration.webp`, `home-project.webp`를 재사용합니다. 생성 프롬프트는 [이미지 기록](../src/assets/images/README.md), 배포 파일·checksum·생성 도구·라이선스는 [자산 manifest](../ASSET-MANIFEST.json)에 있습니다. 이번 변형을 위해 새 raster를 만들지 않았습니다.

## Do's and Don'ts

- 기존 DTCG token과 공용 스타일을 색·폰트·control의 기준으로 사용합니다. 이 문서의 값을 별도 token 파일로 복제하지 않습니다.
- 메인별 본문과 읽기 순서를 유지하고, 공용 헤더·푸터는 동일한 G5 shell을 사용합니다.
- 시연 사례 안내를 실제 실적 주장으로 바꾸지 않습니다. 회사 이름·연락처는 테마 설정값을 사용합니다.
- 전역 `DESIGN.md` 부재와 `PRODUCT.md`의 이전 단계 서술은 이번 문서화에서 수정하지 않았습니다. 전역 문서 정비 시 현재 구현과 대조할 기존 drift입니다.
- 이 기록은 PHP·CSS·token·자산 기록을 대조한 결과입니다. 브라우저 화면 검증, 전체 테마 기능 완료, 판매 ZIP 설치·업데이트·롤백 통과를 뜻하지 않습니다.

# 메인 1 구현·디자인 기록

갱신일: 2026-09-23. 범위: **12개 섹션 메인 1의 원본·빌드·동작 표준**. 기존 사무실 G5 화면 검토는 스택 교정 전 결과입니다. 이번 Embla·Motion·CSS 빌드는 로컬 미리보기에서 별도로 검증하며, 사무실 G5 반영이나 판매 승인을 뜻하지 않습니다.

현재 원본은 `src/php/index_1.php`, `src/php/index.php`, `src/php/mobile/index.php`, `src/styles/home-one.css`, `src/scripts/home-one.ts`입니다. 기존 `.impeccable/review/` 캡처와 독립 reviewer의 `ship`은 확장 이전의 검토 이력입니다. [이번 확장·실화면 기록](../../../../docs/reports/JW-BUSINESS-MAIN1-12-SECTIONS-2026-09-23.md)을 현재 증거로 사용합니다.

## 현재 디자인 규칙

| 항목 | 현재 구현 |
|---|---|
| 색상 | 본문 면·글자·선·아이콘은 DaisyUI `jw-light`·`jw-dark`의 의미 변수를 사용합니다. 사진 위 오버레이와 전략 도표·가상 사이트 목업만 독립 작품의 고정 색을 유지합니다. |
| 서체 | Pretendard Variable. 히어로 제목 `clamp(52px, 5.65vw, 91px)`/800/1.08, 700px 이하 `clamp(43px, 11vw, 60px)`/1.14. 일반 본문은 PC 16~19px, 모바일 14~15px입니다. |
| 배치 | 히어로 슬라이더 → 서비스 아이콘 → 업종 모자이크 → 전략 지도 → 4단계 레일 → 디지털 화면 시안 → 비대칭 사례 갤러리 → 브랜드 실물 → 브랜드 표현 보드 → 펼침형 FAQ → G5 최신글 → 문의의 12개 독립 섹션입니다. |
| 여백·형태 | 주요 내용 최대 1440px, PC 좌우 `clamp(28px, 7vw, 120px)`, 모바일 주요 섹션 23px. 직선 구획과 얇은 선이 기본이며, 원형은 슬라이더 제어·지도 노드·시안 도형에 사용합니다. |
| 깊이 | 사진과 넓은 색면으로 구분합니다. 전략 지도와 디지털 시안의 그림자는 예시 결과물을 주변 설명에서 분리하는 역할입니다. |

**산출물 우선 원칙.** 전략은 결정 지도, 디지털은 가상 기업의 화면, 브랜드는 인쇄물과 포장 사진으로 각각 보여 줍니다. 시연 자료를 실제 고객 실적·예약 기능·도입 성과로 안내하지 않습니다.

**모바일 재구성 원칙.** 700px 이하에서 서비스 3열은 세로 행으로, 전략 SVG는 질문·가설·선택·실행 목록으로 바뀝니다. 디지털 시안은 모바일 화면 하나로 표시합니다. 업종 모자이크·사례 갤러리·브랜드 표현 보드는 좁은 화면에 맞게 재배치합니다. 공통 헤더는 1240px 이하에서 접이식 메뉴로 바뀝니다.

**명시적 재생 원칙.** 슬라이더는 Embla 8.6 + 공식 Fade/Autoplay로 처리합니다. 자동재생은 기본 OFF, 사용자가 켜면 6.5초마다 전환합니다. 직접 조작·hover·키보드 포커스·탭 비활성·히어로 화면 밖에서는 정지하며, 동작 줄이기에서는 재생 버튼을 비활성화합니다. 버튼·dot·ARIA·비활성 슬라이드 focus는 테마 adapter가 책임집니다.

**G5 고정 버튼 경계.** 실제 모바일 G5의 ‘맨 위로’ 버튼이 슬라이더와 겹치는 것을 확인했습니다. 메인 1에서 히어로가 보이는 동안만 이를 숨기고, 화면 아래로 내려가면 다시 표시합니다. 모바일 슬라이더 조작 버튼은 왼쪽으로 모아 44px 이상을 유지합니다.

**절제된 모션 원칙.** 서비스 아이콘은 CSS로 한 바퀴 돌아 거울상이 남지 않게 하고, hover/focus 제어는 daisyUI 버튼과 CSS가 담당합니다. Motion `inView()`는 업종 사진·전략 지도·디지털 화면·단계 레일·대표 사례·브랜드 사진·표현 보드의 진입 시점만 알려 줍니다. 각 블록은 마스크·짧은 위치 이동·확대 정리·순차 배치로 다른 이유를 보여 줍니다. `scroll()`은 데스크톱 레일의 읽기 진행만 표시합니다. 진입 시간은 DTCG의 420/620ms, 이동은 16px 이하입니다. JavaScript가 없어도 본문은 표시되며 동작 줄이기·모바일에서는 레일 진행을 정적으로 둡니다.

이 원칙과 수치는 현재 메인 1만 설명합니다. 전체 테마의 새 디자인 체계나 공통 토큰 승인이 아닙니다.

- 메인 1의 필수 내용 검사는 통과했지만 `quality/contract.json`의 `ready`는 여전히 `false`이며 전체 품질 gate는 실패합니다. 이 단계의 판정은 판매 가능이 아닙니다.
- 아래 캡처와 이전 반영 보고서는 **7개 섹션 시점의 이력**이며, 이번 12개 섹션의 시각 증거로 사용하지 않습니다.

## 미승격 항목과 문서 차이

기존 surface brief는 예약 시연·협업 사진·기존 팔레트 유지 내용을 담고 있어 현재 구현과 다릅니다. PRODUCT의 이전 단계 설명과 함께 문서 차이로만 보고하며 이번 범위에서 수정하지 않았습니다.

현재 구현에 있는 작은 추적 간격 보조 라벨과 문자 화살표·메뉴 기호를 전역 아이콘·타이포그래피 규칙으로 승격하지 않습니다. 시안 내부의 작은 글자도 실제 서비스의 본문·조작 기준으로 정당화하지 않습니다. 이번 교정에서 스크롤 연출의 시간·거리·이징만 기존 DTCG token 원본에 추가했습니다. 새 `DESIGN.md`나 전역 시각 방향은 만들지 않았습니다.

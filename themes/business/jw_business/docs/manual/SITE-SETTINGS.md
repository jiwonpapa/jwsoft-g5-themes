# 사이트 기본 정보 바꾸기

JW-Business는 페이지 빌더나 별도 관리자 설정을 추가하지 않습니다. G5 관리자 메뉴·게시판 설정을 그대로 사용하고, 테마에만 필요한 브랜드·메인·회사 정보는 한 파일에서 관리합니다.

## 설정 파일 만들기

설치된 테마에서 다음 파일을 복사합니다.

```text
custom.example/site.php → custom/site.php
```

`custom/site.php`는 구매자가 바꾼 파일입니다. 테마 업데이트 ZIP에는 이 파일을 넣지 않아 설정을 덮어쓰지 않습니다.

## 바꿀 수 있는 값

| 항목 | 키 | 화면 |
| --- | --- | --- |
| 로고 문자 | `brand.mark` | 헤더·푸터의 작은 브랜드 표식 |
| 사이트명 | `brand.name` | 헤더·푸터 |
| 메인 문구 | `home.eyebrow`, `home.title`, `home.summary` | 히어로 |
| 주요 사업 | `home.services` | 서비스 목록의 제목·설명·링크 |
| 소식 게시판 | `home.news_board` | 메인 최신글 |
| 회사 정보 | `company.*` | 푸터 회사명·대표·주소·연락처·사업자번호 |

G5 상단 메뉴는 관리자 `환경설정 → 메뉴설정`, 문의는 G5 1:1문의, 공지 데이터는 지정 게시판에서 가져옵니다. 같은 값을 `site.php`에 다시 적어 이중 관리하지 않습니다.

## 색상과 사진

- 공개 화면의 라이트·다크 색은 DaisyUI 의미 색상으로 고정한 `jw-light`와 `jw-dark`를 사용합니다.
- 제품 개발자가 색 체계를 바꿀 때는 `tokens/theme.tokens.json`을 수정하고 build합니다.
- 구매자가 로고 문자 이상의 이미지 로고나 메인 사진을 바꾸는 방법은 실제 G5 화면 검증 후 별도 매뉴얼에서 안내합니다.

PHP 배열 문법이 깨지면 테마가 열리지 않을 수 있습니다. 수정 전 파일을 백업하고, 개발 키트 사용자는 `bun run check`를 실행합니다.

## FAQ와 1:1 문의

FAQ 질문·분류·상하단 내용은 기존 그누보드 FAQ 관리에서 수정합니다. 문의 분류·첨부 허용 용량·연락처·알림 설정도 기존 1:1 문의 설정을 사용합니다. PC·모바일 스킨은 모두 테마의 basic을 선택합니다.

JW-Business의 문의 폼은 기본 텍스트 입력을 사용합니다. 본문 형식에서 일반 텍스트, HTML, HTML 줄바꿈을 선택할 수 있습니다. 기존 SmartEditor 설정이 켜져 있어도 문의 화면에 구형 에디터를 로딩하지 않습니다. 고급 에디터는 별도 플러그인 통합 범위입니다.

문의 첨부는 G5 기본 기능인 파일 2개를 사용하며 저장·권한·알림 처리는 코어가 담당합니다. 테마는 알림 서비스나 파일 업로드 서버를 별도로 제공하지 않습니다.

# 홈 디자인 변경

테마의 실제 홈 진입점은 `theme/jw_business/index.php` 하나입니다.

## 제공하는 홈

| 파일 | 구성 |
| --- | --- |
| `index_1.php` | 사진·화면·브랜드 접점을 엮은 종합 에이전시형 |
| `index_2.php` | 분할 슬라이더와 판단 자료가 중심인 전략·의사결정형 |
| `index_3.php` | 안내 표지·인쇄물·디지털 화면을 보여주는 결과물 포트폴리오형 |
| `index_4.php` | 정의서·선택안·인수인계 문서를 보여주는 과정·산출물형 |

사례 사진과 설명은 시연 자료입니다. 실제 사용 전 회사 정보와 프로젝트 내용을
운영사의 자료로 바꾸고, 사실과 다른 실적·주소·전화번호를 게시하지 마세요.

## 변경 방법

1. 현재 `index.php`를 별도 이름으로 백업합니다.
2. 사용할 홈 파일 `index_1.php`~`index_4.php` 중 하나를 선택합니다.
3. 선택한 파일을 같은 폴더의 `index.php`로 복사하여 기존 파일을 교체합니다.

예를 들어 2번 홈을 사용하려면 `index_2.php`의 복사본 이름을 `index.php`로 바꿉니다.

선택 전에는 `/theme/jw_business/index_2.php`처럼 해당 파일을 직접 열어 PC·모바일을
미리 볼 수 있습니다. 미리보기는 그 파일의 전체 본문을 그대로 실행하며 별도 dispatcher나
공통 홈 본문을 사용하지 않습니다. 사이트 기본 홈은 여전히 `index.php`이고, 미리보기 방문이
홈 설정을 바꾸지 않습니다.

각 홈 파일은 헤더 호출, 전체 본문, 푸터 호출을 모두 가진 독립 파일입니다. `partials/`나
공통 홈 renderer를 호출하지 않으므로 선택한 홈은 그 파일에서 직접 수정합니다.

일반 페이지는 G5 웹루트의 `/pages/`에 설치합니다. 각 페이지 역시 `../common.php`,
페이지 제목, 테마 헤더, 전체 본문, 테마 푸터를 직접 포함합니다.

## 메인 1의 디자인·효과 수정

- 문구·섹션·링크는 선택한 `index.php` 본문에서 수정합니다. 기본/선택용 PC 홈과 모바일 홈을 함께 바꿀 때는 각 파일을 개별 확인합니다.
- 의미 색상·모션 시간은 개발 키트의 `tokens/theme.tokens.json`, 고유 배치·사진 크롭은 `src/styles/home-one.css`, 슬라이더·스크롤 동작은 `src/scripts/home-one.ts`가 원본입니다.
- 개발 키트에서 `bun run tokens:build`, `bun run build`, `bun run check:build`를 실행한 뒤 생성된 `theme/css`, `theme/js`와 공유 `theme/js/chunks`를 함께 배포합니다. 설치 ZIP에는 이 결과가 이미 포함되므로 고객 서버에서 Bun·Node·소스 빌드를 실행하지 않습니다.
- `theme/css/*.min.css`나 `theme/js/*.min.js`를 직접 고치면 다음 빌드에서 사라집니다. 슬라이더는 Embla 8.6, 스크롤 연출은 Motion, 버튼은 Tailwind 접두어가 붙은 daisyUI, 색은 `jw-light`·`jw-dark` 토큰을 사용합니다. 다른 라이브러리를 중복 삽입하지 않습니다.

# 메인 7종 사용자 지적 후 교정 계약

형님이 제공한 실제 화면이 이전 검토의 범위와 판정보다 우선합니다. 기존 `ship`은 이번 수정의 승인 근거로 재사용하지 않습니다.

## 요구와 확인한 결함

- 메인2: 모든 폭에서 사진과 글자가 같은 중앙 그리드에 있어야 합니다. 제목의 실제 글자와 사진 사이 최소 32px, 버튼 문자와 아이콘의 수직 중심 차이 2px 이내를 확인합니다. 2560·1920·1280·768·390뿐 아니라 기존 1440도 검증합니다.
- 메인1: 전폭 사진은 유지하고 제목·제어·주요 본문의 독해축을 1440px 중앙 폭으로 연결합니다. 큰 제목을 완화합니다.
- 메인3: 최대 112px 제목을 76px로 완화하고 사례의 시각 자료가 주인공으로 남는지 봅니다.
- 메인4: 중앙 정렬과 CTA는 기존 감사에서 정상입니다. 사용자 지적에 묻어 불필요하게 재설계하지 않고 회귀 검증합니다.
- 제품형: 값싼 NODE 기기 교체 요청은 회전 효과 제거 요청이 아닙니다. AURA의 월넛·패브릭·메탈 콘셉트를 직접 모델링한 Blender 60프레임을 Motion 스크롤에 연결합니다. 모바일·동작 줄이기에서는 정적 화면과 명시적 수동 회전을 제공합니다. 로드 실패·JS 없음에도 제품 이미지는 남습니다.
- 원페이지: 길이만 늘리지 않습니다. 회사·브랜드, 제공 범위, 실제 시각 자료, 진행 절차, 결과물, FAQ, 문의의 이야기 역할을 보완합니다. 제품 11, 서비스 12, 공간 12개 독립 섹션입니다.

## 시각·구조 방향

THESIS: 사진과 실제 도해를 읽을 수 있는 크기의 한국어 제목으로 연결하고, 회사의 설명과 사용자의 선택에 필요한 자료를 한 페이지에서 완결합니다.

OWN-WORLD: 기존 Pretendard·DTCG token·Tailwind 4·daisyUI 5 jw-light/jw-dark·Lucide·Motion·Embla를 유지합니다. 신규 전역 색상·라이브러리·PHP 조립 구조를 도입하지 않습니다.

STORY: 메인1은 종합 서비스, 2는 사업 선택, 3은 시각 포트폴리오, 4는 과정과 산출물입니다. 제품형은 브랜드→형태→재료→360도→사용→안내→문의, 서비스형은 회사·역할→제공 범위→설계 자료→진행→협업 조건, 공간형은 스튜디오→공간 사례→업무 범위→절차→자료→문의로 구별합니다.

FIRST VIEWPORT: 메인2 사진과 문장은 최대 1440px 안의 두 열과 실제 gap으로 구성합니다. 800px 이하에서는 문장 다음 사진으로 전환합니다. 텍스트만 키워 빈 곳을 메우지 않습니다.

FORM: 사용자 지적에 따른 code-led refinement입니다. 페이지 소유 PHP는 완성형 그대로, CSS 원본에서 수정하고 Vite 빌드 결과를 배포합니다. 원페이지의 회사 소개는 각각 브랜드 오디오 마크, 팀 작업 사진, 공간 모형 검토 사진으로 표현을 구분합니다.

INTERACTION: 회전은 평면 사진의 CSS 회전이 아닌 Blender 입체 모형의 60개 각도입니다. Motion.scroll을 사용하고 자동 움직임을 끌 수 있습니다. 수동 range는 키보드 Home/End/화살표를 지원합니다. 중간에 수동 전환해도 스크롤 영역 높이를 갑자기 줄이지 않습니다.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## 증거 범위

배포는 사무실 Ubuntu g5themes.test만 대상입니다. 비회원 7페이지의 56상태 검사, 메인1·2 모든 슬라이드, 제품 회전·키보드·모바일·줄인 동작·정적 대체, 내장 브라우저 실화면 및 새 독립 검토를 준비합니다. 수집 완료와 디자인 판정은 별개입니다. 기존 전체 품질 차단과 일반 페이지 문제는 면제하지 않습니다. 판매 ZIP·회원 전체·실물 기기 검증은 이번 범위 밖이며 상품 전체 판매 가능으로 확대하지 않습니다.

## 독립 검토 교정 기록

메인1 히어로의 중복 소제목과 메인3의 장식용 영어 번호 라벨을 제거했습니다. 제품은 사진에 없는 로고·좌측 추가 조작부·발을 제거하고, 촘촘한 패브릭과 브러시드 메탈, 전용 월넛 텍스처로 정합성을 맞췄습니다. 나뭇결 원본·생성 프롬프트는 `onepages/design/aura-walnut-albedo.png`와 sidecar에, Blender 원본은 외부 텍스처까지 pack한 `.blend`에 보관합니다. 브라우저에 공급하는 것은 WebP60장뿐입니다. 바닥 shadow catcher를 제거해 테마 배경에 사각 흔적이 남지 않게 했습니다. 포스터에는 동기 디코딩을 사용하고, 재배포 때 이전 프레임 캐시가 남지 않도록 파일 수정 시각을 URL 버전에 반영합니다.

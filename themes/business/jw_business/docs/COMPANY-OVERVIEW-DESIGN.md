# 기업개요 5종 — 제작 방향

2026-09-22. 사용자 지시: 다섯 개를 서로 다른 섹션/블록과 동작으로 구현하고 직접 시야 검증. 기존 daisyUI 팔레트·Pretendard·공통 헤더/푸터를 유지하는 확장 작업이다.

## Direction contract

THESIS: 같은 기업 정보를 서로 다른 읽기 순서로 소개한다. #1은 소개와 사람, #2는 움직이는 현장과 정보표, #3은 공간을 따라가는 이야기, #4는 사업과 사례, #5는 깊이 읽는 편집물이다.

OWN-WORLD: 기존 jw-light/jw-dark 토큰, Pretendard, Lucide. 사진은 기존 출처가 기록된 3개 업무 공간/협업 이미지 재사용. 큰 사진과 충분한 섹션 간격, 단정한 선과 읽기 쉬운 본문을 사용한다. 신규 고정 브랜드 색상과 임의 실적 숫자를 만들지 않는다.

STORY: 어떤 기업인지 → 무엇을 연결하는지 → 일하는 방법/공간/사례 → 기업 정보 또는 다음 행동. 기업 정보·사례는 시연용이라는 표시를 모든 페이지에 둔다.

FIRST VIEWPORT: #1 좌측 제목과 우측 세로 사진. #2 큰 짧은 제목 아래 가로 사진 슬라이더. #3 화면을 채우는 사진과 사진 위 제목. #4 제목과 비대칭 사진 모자이크. #5 넓은 타이포그래피와 사진, 아래 고정 목차와 본문.

FORM: 사용자 지정 다섯 표현형을 코드로 직접 구현한다. #2 Embla 기반 터치 슬라이더(자동 재생은 명시적으로 시작), #3 제한된 스크롤 이미지 이동(모바일/reduced-motion에서는 정지), #5 고정 목차와 앵커 이동. 동일 배열을 데이터만 바꿔 5회 출력하지 않는다.

FINISH: PC/모바일 5종 직접 스크린샷 확인, 슬라이더·스크롤 동작과 라이트/다크 확인, 차이·미검증 범위 기록. 전체 테마 출시 검증과는 별개다.

## 구현 및 편집 위치

- 본문: `src/php/pages/company-overview/1.php` ~ `5.php`. 번호별로 독립 구성하며 기존 `/pages/company-overview-N.php` 경로를 유지합니다.
- 공통 출력: `src/php/pages/company-overview.php`. 페이지별 설명 메타, 헤더·푸터, 디자인 비교 링크를 출력합니다.
- 스타일: `src/styles/company-overview.css`. `.jwc` 아래로 한정합니다.
- 동작: `src/scripts/company-overview.ts`. 슬라이더가 있는 페이지와 패럴랙스가 있는 페이지에서만 초기화합니다.
- 슬라이더: Embla Carousel 8.6.0, MIT. https://github.com/davidjerleke/embla-carousel/tree/v8.6.0
- 원문 라이선스: 배포 테마 `licenses/embla-carousel.txt`에 포함합니다.
- 자동 재생은 기본 OFF, 사용자가 켜면 5.5초 간격. 수동 조작·키보드 진입 시 정지하고, 탭 비활성·화면 밖에서는 일시 정지합니다.
- 패럴랙스는 데스크톱에서 ±48px 범위. 모바일 및 모션 감소 설정은 정지 이미지입니다.
- 사진은 기존 시연용 WebP 3종을 재사용합니다. 실적 숫자나 인증을 만들어 넣지 않습니다.
